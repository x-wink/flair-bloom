# 规则玩法

对应应用内教程 `rules`。目标：学会两种连发的区别、规则卡上每个字段、高级设置里「启动键与连发键分开」、切换连发的互斥分组。

## 解决什么

上手三步只加了一条按压规则。想做「按一下就持续触发的宏」「多段宏之间一键切换互不打架」「按住侧键连左键」，需要切换连发、高级设置和分组。

## 步骤大纲

| #   | 目标锚点        | 讲什么                                                                                                                                 | 实操       |
| --- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| 1   | `filter`        | 按压连发适合平 A、等 CD 戳键；切换连发适合长时间挂机、采集、一键宏                                                                     | 无         |
| 1a  | `add-hold`      | 前置步：没有按压规则时才出现——「后面两步要在规则卡上讲，先点这里添加一条」；已有规则则跳过                                             | 规则数增加 |
| 2   | `rule-latest`   | 规则卡：连发按键、间隔（毫秒，可 ±10 步进）、启用开关、拖动排序。多条一起连时软件自动控速，不会停不下来                                | 无         |
| 3   | `rule-advanced` | 高级设置：把「启动键」和「连发键」分开，比如按住侧键连左键、按 F 连滚轮。切换连发还能单独设「停止键」                                  | 无         |
| 4   | `add-toggle`    | 切换连发规则从这里加（筛选已由 prepare 切过去），只看不点                                                                              | 无         |
| 5   | `add-group`     | 互斥分组：把几条切换连发规则拖进同一组，组内同一时刻只跑一条——多段宏按 2 会自动停掉按 1 那条                                           | 无         |
| 6   | 无              | 完成。规则按键框描边变红 / 变黄是冲突提醒：热键盖住了触发键、A 的连发键是 B 的触发键之类；红的让规则失效、黄的只是可能干扰，换键即恢复 | 无         |

## 常见坑

- 没有按压规则时第 2、3 步没有卡可指：前置步 1a 让用户先加一条；用户跳过 1a 仍为空，则第 2、3 步各自 `prepare` 返回 `skip`，直接到第 4 步，教程不会指着空处讲。
- 规则卡内锚点（`rule-key` / `rule-enable` / `rule-advanced`）每张卡都有，引擎先在 `rule-latest` 卡内找、找不到再全局找，保证高亮的卡与实操判定看的「最后一条规则」是同一张。
- 第 4、5 步要先切到「切换」筛选，`prepare` 负责。
- 修饰键（Shift / Ctrl / Alt / Win）只能绑全局热键，连发规则不收；录入时会被拒并提示原因，教程不用再讲。
- DD 驱动下切换连发的启动键与连发键不能相同，录入时会提示到高级设置里分开。

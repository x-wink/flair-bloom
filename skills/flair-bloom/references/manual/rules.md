# 规则玩法

对应应用内教程 `rules`。目标：看懂统一列表与筛选、规则卡上每个字段、点标签换模式、高级设置里「启动键与连发键分开」。规则组另有一组教程 [groups](groups.md)。

## 解决什么

上手三步只加了一条长按规则。想做「按一下就持续触发的宏」「按住侧键连左键」，需要切换连发和高级设置；列表里两种规则混在一起，要知道怎么筛、怎么换模式。

## 步骤大纲

按项淡化重复信息：触发键与任一目标键相同时，触发键及其 label 一起淡化；切换的停止键与触发键或任一目标键相同时，停止键及其 label 一起淡化。淡化的热键框隐藏边框并保留尺寸，录键、键盘聚焦和冲突时恢复对应边框。目标键保持原色。例如启动 Q、输出 Q、停止 E，只淡化启动 Q，输出 Q 和停止 E 保持原色；启动 Q、输出 E、停止 Q 时，只淡化停止 Q。运行、暂停、录键和冲突提示优先显示。

独立触发、独立停止或多步序列沿用现有高级规则判定，「高级设置」入口用实心三角，展开与收起时切换方向；普通规则保留原箭头。「连发序列」只有一步时整个章节淡化，录制与添加步骤仍可用，序列错误提示恢复正常显示。卡片整体透明度和运行逻辑保持原样。

「我要新建」的三项副标题分别是：长按连发「按下开始·松开结束」、切换连发「按一次开始·再按结束」、规则组「开始时自动停止其他·智能互斥」。操作区在规则较少时保持贴底，规则较多时列表滚动。

新建长按连发默认使用 Q，新建切换连发默认使用 F，启动键与连发按键相同；切换连发再按 F 停止，也可在高级设置里单独设置停止键。

竖版底部左侧「我要新建」菜单统一提供长按连发、切换连发和规则组。顶部有全部、长按、切换、规则组四项筛选；规则组标签的数字是组数，只显示已分组的规则及完整成员，允许组内排序与跨组拖入。

拖动卡片时，面板底部覆盖渐变删除区，显示垃圾桶图标、「拖入规则」与「Ctrl 强删，跳过确认」。进入该区域后高亮并显示「松手删除」；按住 Ctrl 时动态改为「松手强制删除」，松开 Ctrl 恢复普通删除。以放下时的 Ctrl 状态为准：普通放下打开与规则菜单「删除」相同的确认框，确认才删除、取消保留；按住 Ctrl 放下则跳过确认直接删除，不记忆到下一次操作。删除区只在拖动期间出现，不挤占列表空间。

## 连发序列与录制

每条规则的输出是一份“按键＋间隔”队列，单键连发就是一步队列，触发方式仍为长按／切换。每条规则最多 256 步，每步有效间隔 10～10000ms；末步间隔结束后回到首步。间隔包含本步按压时长，多条规则争用按键时可能延后，软件不跳步或追赶补发。

切换连发的启动热键与停止热键在高级设置中并排编辑；主行修改连发按键不会改动启动热键。独立长按键保留在主行，方便看清实际需要按住哪个键。

运行中的下一步必须等待上一步成功发送完成后的完整间隔，截止前不会输出。迟到只顺延，队列仍按序执行完；卡片记录最近和最大延后时间，不因迟到自动停止。用户主动松手／切换停止、全局急停与输入通道失败分别按停止规则处理。

1. 单键时在规则卡主行编辑按键与间隔，高级设置不重复显示单步列表。展开「高级设置」可看到并排的带图标「录制宏」与「添加步骤」；多步规则也可点击主行的序列摘要展开。
2. 添加第二步后显示列表，可添加、复制、删除或上下移动步骤，分别设置按键与间隔；删回一步后隐藏列表。修改与规则卡其他字段一样，校验后立即生效并自动保存，收起高级设置不撤销编辑。更新会停止旧运行，下次启动从第一步开始；校验失败会提示并恢复引擎规则，写盘失败会提示并保留可重试快照。
3. 点「录制宏」时检查全局开关：已开启则先询问是否结束运行并录制，取消确认不影响当前运行；确认后先关闭全局并停止输出，再开始录制。未开启则直接录制，无开始提示和倒计时。录制开始后顶层浮层遮住面板并限制焦点，不能操作背景控件；实时预览每步按键及间隔，录制预览和操作按钮都在浮层内。
4. 依次点按普通键盘键，再按 F12 或点「结束录制」。F12 以快捷键形式显示在等高按钮内。录制保留真实重复点按，忽略系统自动重复，最多 5 分钟／256 步；鼠标、修饰键、重叠按键或超范围间隔会结束录制并提示检查已录步骤。全局停止热键也能结束录制，全局开关关闭时仍生效，停止键不进入序列，结束后不自动恢复运行。
5. 结束后的浮层保留预览，左侧「重录」、右侧「采用」，没有间隔输入框。重录会清空预览并开始新会话，仍检查全局开关并按需确认；只有采用才替换当前序列并自动保存，空录制不能采用。右上角关闭会停止并放弃本次录制，保留原序列；结果页按 Escape 也可放弃关闭，录制中的 Escape 仍是普通录制键。末步回到首步默认使用连发统一默认值 **10ms**，采用后可在步骤列表中修改。按住时间按普通点按播放，停止录制的等待时间不会混入末步间隔。点击背景不会关闭浮层。

松手或切换停止后进度清空；同组长按临时插队则释放正在按的键，冻结队列位置和剩余等待，松手后继续。暂停期间停止／替换规则会丢弃旧进度；全局停止、换配置、切后端和退出都清理运行与录制。滚轮作为长按触发键只允许一步点按。

停止、保存规则或切换配置／输入模式后，仍按住的键需要先松开再触发，系统自动重复不会重新开启连发。按键释放失败时软件保留记录并自动重试，相同目标键的其他队列暂缓，释放成功后按原顺序继续。出现「调度线程异常」时输出已停止，面板和浮窗会提示重启；重新打开总开关不能恢复故障线程。

如果原有输出尚未确认停止或按键释放失败，输入模式切换和录制会被拒绝；输入模式保持当前值，请停止输出后重试。

软件只发送按键，不判断目标程序是否执行成功。运行卡片和浮窗显示队列步骤，发送接口失败会停止对应规则并显示失败位置；松开插队键不会自动重放失败队列，需要主动重新启动。用户真实按住的 Ctrl 等修饰键仍按系统语义参与输出，队列不提供组合键配置或物理键隔离。

## 常见坑

- 正在连发的卡片有明显描边、淡底和呼吸光晕；同组插队暂停时变淡、停止呼吸，并显示 ⏸。系统启用「减少动态效果」时保留静态运行高亮，避免失去状态提示。
- 没有长按规则时第 2～4 步没有卡可指：前置步 1a 让用户先加一条；用户跳过 1a 仍为空，则第 2～4 步各自 `prepare` 返回 `skip`，直接到第 5 步，教程不会指着空处讲。
- 规则卡内锚点（`rule-key` / `rule-enable` / `rule-mode` / `rule-advanced`）每张卡都有，引擎先在 `rule-latest` 卡内找、找不到再全局找，保证高亮的卡与实操判定看的「最后一条规则」是同一张。「最后一条」跳过被筛掉的和折叠组里的规则——折叠组内的卡不渲染，锚点无处落脚。
- 第 1a～4 步把筛选切到「长按」，让 `rule-latest` 落在长按卡上；第 5 步切回「全部」。`prepare` 负责。
- 修饰键（Shift / Ctrl / Alt / Win）只能绑全局热键，连发规则不收；录入时会被拒并提示原因，教程不用再讲。
- 网吧模式允许切换连发的启动 / 停止键与连发键相同；同键启停可能误判，可关闭全局开关或正常退出应用，停止连发并释放按键。

# 互斥组与多段宏

对应应用内教程 `groups`（`apps/main/src/windows/panel/tour/tours/groups.ts`）。目标：用户能说出「组里同一时间只跑一条；切换是换一条，长按是插队、松手还回去」，并看懂组头状态。

## 解决什么

多段宏（按 1 跑宏 A、按 2 换宏 B）如果不放进同一组会同时跑、互相打架；跑宏的时候想临时按住一个键连发，又不想宏停掉重开。互斥组把两件事都管了：同组同一时间只跑一条，切换规则互相换班，长按规则按住时插队、松手把组还回去。

## 步骤大纲

| #   | 目标锚点        | 讲什么                                                                                                                         | 实操                                                   |
| --- | --------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------ |
| 1   | 无              | 气泡内四拍时间线：按 A 宏A 跑 → 按 B 宏A 停、宏B 跑 → 按住长按键 宏B 暂停、长按跑 → 松开 宏B 接着跑。「切换是换人，长按是插队」 | 无                                                     |
| 2   | `add-group`     | 平时从这里新建分组再拖入；这次点气泡里「建示例组」建「示例·多段宏」：两条切换、一条长按，全部停用，键位避开已在用的键         | 出现示例组                                             |
| 3   | `group-latest`  | 组容器：拖进拖出、⋯ 菜单也能移入；组头那句话就是组的规则；组里只有一条没意义                                                   | 无                                                     |
| 4   | `group-header`  | 三件事：启用示例组三条规则、打开总开关、按一下宏A 的键——组头亮起「宏A 在跑」                                                   | 宏A 在跑                                               |
| 5   | `group-header`  | 按一下宏B 的键：宏A 自动停、宏B 接班——多段宏切换                                                                               | 宏B 在跑且宏A 不在跑                                   |
| 6   | `group-header`  | 按住长按键别松：在跑的宏变 ⏸、长按开始连发；松手后宏自己接着跑                                                                 | 先看到某条示例宏被暂停，再看到它恢复运行且长按已松开   |
| 7   | 无              | 完成。长按规则不进组就和切换同时跑、互不影响；气泡里「删除示例组」一键删掉示例组的三条规则                                     | 无                                                     |

## 常见坑

- 示例组键位：切换从 1/2、3/4、5/6、7/8、9/0、Z/X 里挑第一对没被占用的，长按从 V、B、N、M、H、J 里挑，连发键固定 Q / E / R。「占用」= 任一规则的启动 / 连发 / 停止键 ∪ 三个全局热键——撞上用户自己的规则会同时触发、冲突提醒变红。全被占用时不建，提示腾出键位，可跳过这一步。
- 示例组的三条规则 id 固定（`sample-macro-a` / `sample-macro-b` / `sample-hold`），已存在就不重复建；用户删掉其中任意一条，第 4～6 步没法做，直接跳到第 7 步。没有任何分组时第 3 步也跳过。
- 第 4～6 步依赖全局开关与注入：连发键 Q / E / R 会打进**当前前台窗口**，做这几步时保持面板在前台（面板没有文本框聚焦时无副作用）；切到别的窗口再按，Q / E / R 会打进那个窗口。
- 第 6 步不要求第 4、5 步的顺序：最后在跑的是宏A 还是宏B 都行，看到它被暂停再恢复就算完成。
- 「删除示例组」删的是组内规则，不是「解散」（解散只清分组、规则保留）。
- 暂停 / 恢复不播报；只有切换规则真正开始 / 结束才播。

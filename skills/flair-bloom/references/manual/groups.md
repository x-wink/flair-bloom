# 规则组

对应应用内教程 `groups`（`apps/main/src/windows/panel/tour/tours/groups.ts`）。目标：用户能说出「组里同一时间只跑一条；切换是换一条，长按是插队、松手还回去」，并看懂组头状态。

## 解决什么

规则组常用于多段宏自动切换，也可用于其他需要轮换的连发规则。同组同一时间只运行一条：切换规则互相替换，长按规则按住时插队、松手后恢复原规则。

从底部「我要新建」菜单选择「规则组」，会创建「规则组 1」等不重名的组，并复用现有规则创建逻辑加入两条切换规则：主键区 1 和 2 分别作为各自的启动键与连发按键，间隔为默认 10ms，默认停用，设置好后再启用。新组自动展开并进入名称编辑。规则菜单中的「新建规则组」使用同一逻辑，再把当前规则移入；已有规则和自定义组名保持原样，默认按键不因占用情况自动改成其他键，启用前可按冲突提示调整。

分组底部「拖入规则」放置区仅在拖拽卡片时以渐变覆盖层显示，拖拽结束或取消后收起；覆盖层不占布局高度，分组及后续卡片的位置保持稳定。规则拖进组的任何区域时，整组高亮，底部提示改为「松手放置」。悬停组内卡片时，插入线表示放到该卡片前；悬停底部区域本身时，底部区域额外高亮，表示放到组尾。组尾放置区与面板删除区共用渐变拖放组件。跟随鼠标的副本使用独立的不透明快照，原卡保持 40% 不透明度。

组只随实际成员存在：删除或移出最后一条规则后，空组自动解散，不显示空壳。旧版待命空组未落盘，升级时不恢复；有成员的旧组及名称保持原样。组内规则全部停用时仍有成员，组会保留。

组头箭头在折叠时朝右、展开时朝下。全局开启时，组头副标题显示当前运行与暂停规则，均为空时显示「未在运行」；折叠后仍可见，全局关闭时隐藏副标题。组内不重复显示独立状态区域。较长的状态项省略显示，悬停可查看完整内容。教程的 `group-header` 锚点覆盖稳定的组头，在开关状态变化时保持可用。

点击组头「解散」后，确认框提供「同时删除组内规则」。每次打开时，组内规则全部停用则默认勾选，只要有规则启用则默认不勾选；按启用设置判断，与规则当前是否正在运行无关，不记忆上次勾选。不勾选时确认按钮为「解散」，只解除组内关系并保留所有规则；勾选后按钮变为「清空并解散」，确认后删除该组所有规则，其他组及未分组规则不受影响。取消勾选会恢复「解散」，取消确认不会修改规则。

## 步骤大纲

| #   | 目标锚点        | 讲什么                                                                                                                         | 实操                                                   |
| --- | --------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------ |
| 1   | 无              | 气泡内四拍时间线：按 A 规则 A 跑 → 按 B 规则 A 停、规则 B 跑 → 按住长按键 规则 B 暂停、长按跑 → 松开 规则 B 接着跑。「切换是换人，长按是插队」 | 无                                                     |
| 2   | `add-group`     | 新建规则组默认带按键 1、2 的两条停用切换规则，也能拖入已有规则；这次点气泡里「建示例组」建「示例规则组」：两条切换、一条长按，全部停用，键位避开已在用的键 | 出现示例组 |
| 3   | `group-latest`  | 组容器可拖进拖出、从菜单移入；组头显示名称，副标题显示运行与暂停规则，内部不重复展示状态。同组只运行一条，切换替换，长按插队 | 无 |
| 4   | `group-header`  | 启用示例组三条规则、点击「开始运行」、按一下规则 A 的键，组头显示正在运行的按键 | 规则 A 在跑 |
| 5   | `group-header`  | 按一下规则 B 的键：规则 A 自动停、规则 B 接班——多段宏切换                                                                               | 规则 B 在跑且规则 A 不在跑                                   |
| 6   | `group-header`  | 按住长按键别松：在跑的宏变 ⏸、长按开始连发；松手后宏自己接着跑                                                                 | 先看到某条示例宏被暂停，再看到它恢复运行且长按已松开   |
| 7   | 无              | 完成。长按规则不进组就和切换同时跑、互不影响；气泡里「删除示例组」一键删掉示例组的三条规则                                     | 无                                                     |

## 常见坑

- 示例组键位：切换从 1/2、3/4、5/6、7/8、9/0、Z/X 里挑第一对没被占用的，长按从 V、B、N、M、H、J 里挑，连发键从 Q、E、R、T、Y、U、I、O、P 里依次挑三个没被占用的。「占用」= 任一规则的启动 / 连发 / 停止键 ∪ 三个全局热键——撞上用户自己的规则会同时触发、冲突提醒变红。全被占用时不建，提示腾出键位，可跳过这一步。
- 示例组的三条规则 id 固定（`sample-macro-a` / `sample-macro-b` / `sample-hold`），三条都在才算有示例组，已有就不重复建；只剩部分（删了一条、拖出组）时点「建示例组」会先清掉残留的示例规则再重建。示例规则只按固定 id 认，用户自建的同名组、拖进示例组的自己的规则都不受影响。用户删掉其中任意一条，第 4～6 步没法做，直接跳到第 7 步。没有任何分组时第 3 步也跳过。
- `group-latest` / `group-header` 锚点落在示例组上（没有示例组时落在最后一个组）：用户自建的组排在示例组后面时，高亮的仍是示例组及其组头，组头包含全局开启时的状态区。
- 第 4～6 步依赖全局开关与注入：示例组的连发键会打进**当前前台窗口**，做这几步时保持面板在前台（面板没有文本框聚焦时无副作用）；切到别的窗口再按，连发的字母会打进那个窗口。
- 第 6 步不要求第 4、5 步的顺序：最后在跑的是规则 A 还是规则 B 都行，看到它被暂停再恢复就算完成。
- 第 7 步「删除示例规则」只删三条示例规则（哪怕已拖出组），是删规则不是「解散」；用户拖进示例组的自己的规则留下，成为一个普通组。只剩部分示例规则时按钮也在。
- 暂停 / 恢复不播报；只有切换规则真正开始 / 结束才播。

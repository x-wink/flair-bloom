# 规则组

对应应用内教程 `groups`（`apps/main/src/windows/panel/tour/tours/groups.ts`）。目标：创建规则组、设置组内规则、按键切换。

## 解决什么

规则组常用于多段宏自动切换，也可用于其他需要轮换的连发规则。同组同一时间只运行一条：开关规则互相替换，长按规则按住时插队、松手后恢复原规则。

从底部「我要新建」菜单选择「规则组」，会创建「规则组 1」等不重名的组，并复用现有规则创建逻辑加入两条开关规则：主键区 1 和 2 分别作为各自的启动键与连发按键，间隔为默认 10ms，默认停用，设置好后再启用。新组自动展开并进入名称编辑。规则菜单中的「新建规则组」使用同一逻辑，再把当前规则移入；已有规则和自定义组名保持原样，默认按键不因占用情况自动改成其他键，启用前可按冲突提示调整。

分组底部「拖入规则」放置区仅在拖拽卡片时以渐变覆盖层显示，拖拽结束或取消后收起；覆盖层不占布局高度，分组及后续卡片的位置保持稳定。规则拖进组的任何区域时，整组高亮，底部提示改为「松手放置」。悬停组内卡片时，插入线表示放到该卡片前；悬停底部区域本身时，底部区域额外高亮，表示放到组尾。组尾放置区与面板删除区共用渐变拖放组件。跟随鼠标的副本使用独立的不透明快照，原卡保持 40% 不透明度。

组只随实际成员存在：删除或移出最后一条规则后，空组自动解散，不显示空壳。旧版待命空组未落盘，升级时不恢复；有成员的旧组及名称保持原样。组内规则全部停用时仍有成员，组会保留。

组头箭头在折叠时朝右、展开时朝下。全局开启时，组头副标题显示当前运行与暂停规则，均为空时显示「未在运行」；折叠后仍可见，全局关闭时隐藏副标题。组内不重复显示独立状态区域。较长的状态项省略显示，悬停可查看完整内容。教程的 `group-header` 锚点覆盖稳定的组头，在开关状态变化时保持可用。

点击组头「解散」后，确认框提供「同时删除组内规则」。每次打开时，组内规则全部停用则默认勾选，只要有规则启用则默认不勾选；按启用设置判断，与规则当前是否正在运行无关，不记忆上次勾选。不勾选时确认按钮为「解散」，只解除组内关系并保留所有规则；勾选后按钮变为「清空并解散」，确认后删除该组所有规则，其他组及未分组规则不受影响。取消勾选会恢复「解散」，取消确认不会修改规则。

## 步骤大纲

教程只保留基础流程，每步最多三句，每句不超过十字。完整功能说明保留在本篇参考段落。

| 步骤 | 目标锚点 | 气泡文案 | 实操判定 |
| --- | --- | --- | --- |
| 1 | add-group | 这里添加规则组；同组只运行一条 | 无 |
| 2 | group-latest | 这里设置组内规则；启用后才会运行 | 无 |
| 3 | global | 开始后按键切换；原规则自动停止 | 无 |

## 常见坑

- 教程只定位现有控件，不创建、删除示例规则，也不实际演练插队。没有规则组时跳过第二步。
- `group-latest` 和 `group-header` 指向最后一个规则组，运行状态仍只显示在组头。
- 暂停与恢复不播报，开关规则真正开始与结束才播报。

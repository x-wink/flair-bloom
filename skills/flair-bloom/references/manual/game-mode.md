# 游戏模式与驱动

对应应用内教程 `game-mode`。目标：让用户明白为什么游戏里要用「游戏模式」、怎么装驱动、装完要做什么。

## 解决什么

「网吧模式」的说明是「方便快捷·无需重启」，内置 DD SDK，支持同键切换连发与横版键鼠图；新装默认使用并开启「以管理员模式启动」，首次按系统提示授权即可。「游戏模式」的说明是「安全稳定·剑三推荐」，使用 Interception 驱动，首次安装后需要重启 Windows 并以管理员运行。「轻量模式」的说明是「网页办公·游戏无效」，靠系统 SendInput 注入，无需驱动和管理员权限。「外设模式」给有外设驱动的人：按键经串口发给外设驱动，由它作为真实 USB 键鼠敲出，即插即用、不要管理员。

升级时，已保存的轻量模式只迁移一次为网吧模式，保留游戏模式、外设模式及明确设置的启动偏好；未设启动偏好且未开机自启的轻量模式用户默认开启管理员启动，之后手动选择轻量模式不会再次迁移。已有配置未绑定全局开关且 F1 未被占用时，一次性补上 F1，保留自定义绑定。

## 常见坑

- 安装、卸载、清理残留或排除设备槽问题后，请点击 Windows「开始 → 电源 → 重启」。开启快速启动时，关机再开机可能沿用内核与驱动状态，不能代替这里要求的重启；应用“以管理员重启”也只是重启应用。参见 [Microsoft 的快速启动说明](https://learn.microsoft.com/en-us/windows/win32/power/system-power-states)。
- 首次安装成功后先切回轻量模式；启动恢复及手动切换游戏模式会重新检查运行通道和可读取硬件 ID 的键盘。通道打不开或没有可用键盘才阻止启用；仅缺少鼠标时键盘仍可使用，鼠标注入可能回退通用通道。临时回退不覆盖原先保存的模式，弹窗可直接打开诊断修复。需要管理员权限时先授权重启，再判断驱动可用性，避免把权限不足当成驱动损坏。
- Interception 是键盘、鼠标各 10 个槽，不能互借。恰好占满 10 个槽、Windows 类设备编号偏高或类设备编号采集失败，只在诊断中提示，不据此禁用仍可读取的设备。若新接入设备失效，请重启 Windows；拔插和退出应用不能回收驱动槽位。诊断报告记录当前／保存的模式、可读键鼠槽号、Windows 类设备编号、启用判定及其原因，不凭编号要求清理或重装驱动。
- 切换模式会先停止连发、释放已注入按键，再释放本应用不用的 DD SDK / Interception context；正常退出也会显式释放。诊断修复可只读检查 DD 设备占用，DD 63330 与已停用的 DDHID 63340 残留分开处理。卸载 DLL 不等于系统驱动卸载，也不保证第三方 SDK 内部句柄已关闭；仍有占用时先正常退出相关程序。仅确证 Interception 服务对应驱动文件缺失时推荐清残留，首次安装待重启和独占问题不会直接触发清理。
- ☰ → 诊断修复 → 导出诊断报告会在桌面生成 `flair-environment-*.txt`，包含驱动、安全策略、相关错误日志和显示环境；应用内报告还附带实际 WebView 缩放。仅采集并写报告，不执行修复。无法打开应用时，可运行独立的 `scripts/diagnose-environment.ps1`（或将同目录的 `diagnose-environment-oneclick.cmd` 一起发送后双击）；无需管理员，权限不足会记录。旧脚本名称保留为兼容入口，需与新脚本放在一起，也输出统一的文本报告。

- 教程不真的触发安装：安装要提权与重启，放在教程里做不完整，只讲到哪里点。
- 模式菜单展示用途说明；设置中的输入模式还显示管理员权限、驱动就绪及外设连接状态。
- 网吧模式的同键启停可能误判，导致连发自停或按原键停不下；可关闭全局开关或正常退出应用，停止连发并释放按键。外设模式仍与横版键鼠图互斥。
- 外设模式：只有检测到硬件并握手确认固件后才显示在模式菜单和设置中，普通 USB 串口不算外设驱动。只插外设驱动的原生 USB 口即可（开发板另一个 UART 口是烧录用的，插不插都不影响）；前面板口偶尔握手失败，插主板后置口。不在外设模式时，插上外设驱动或启动时它就插着，都会弹窗问要不要切过去（上次就是外设模式则启动时直接恢复）；外设模式下拔掉会提示并回退到轻量模式，插回再问一次。后台自动识别乐鑫芯片的开发板；其他芯片可先在诊断修复中扫描并确认硬件。切换连发的启动 / 停止键仍不能等于连发键。媒体键不在外设驱动的键盘报文里，会改走通用通道。
- 外设驱动插着却打不出字：☰ → 诊断修复。「驱动状态」里外设驱动一行逐个列出 USB 串口认没认出来（转串口芯片的口会跳过，那是开发板的烧录口）。装过游戏模式驱动的电脑，这个驱动每类设备只有 10 个槽，拔插键盘、装卸虚拟键盘都会占槽且不归还，满了之后新插的外设驱动键盘输入会被吞、鼠标可能还能用；诊断会报「外设驱动的输入被吞」，重启电脑即恢复。

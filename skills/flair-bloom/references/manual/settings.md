# 热键、声音与外观

对应应用内教程 `settings`。目标：设好全局热键（游戏里一键开关、收起 / 唤出面板）、按需开语音播报、换主题。

## 解决什么

游戏里不想切出来点面板：全局热键一键开关所有连发、显隐面板。看不到屏幕时靠声音知道连发开没开。主题颜色跟门派走。

全局运行操作在主面板、浮窗提示与托盘菜单中统一显示为「开始运行」／「结束运行」；未运行时点击开始，运行后点击结束，快捷键仍用于同一开关。

出厂配置默认用 **F1** 切换全局开关，停止键与面板显隐键默认未绑定。升级时，未绑定全局开关且 F1 未被其他热键或规则占用的已有配置会一次性补上 F1；保留自定义绑定，迁移后再清空不会补回。新建配置继承当前配置的热键。新装默认开启「以管理员模式启动」，用于网吧模式和游戏模式；迁移轻量模式时，未设启动偏好且未开启开机自启的用户也默认开启管理员启动；明确设置的启动偏好保持原样。

## 步骤大纲

| #   | 目标锚点                    | 讲什么                                                                                                                                                                                                                                                                                                                                                             | 实操 |
| --- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| 1   | `settings-hotkeys`          | 三个热键：全局开关（可另设停止键）、面板显隐。只能是键盘键，Shift / Ctrl / Alt / Win 也行、左右分开识别；三者不能重复。点按键框开始捕获、按下要绑的键；已绑定的框上右键清除                                                                                                                                                                                        | 无   |
| 2   | `settings-hotkeys`          | 绑了右 Alt 又绑左 Ctrl 会互相牵连（AltGr 键盘布局），界面会提示                                                                                                                                                                                                                                                                                                    | 无   |
| 3   | `settings-sound`            | 声音播报：全局启用 / 停用、切换连发开始 / 结束四个时机各自可开关；每个时机可选「朗读」文字或「音频」文件，能调音量、语速、音调                                                                                                                                                                                                                                     | 无   |
| 4   | `settings-general-theme`    | 外观：明亮 / 黑暗 / 跟随系统，21 套门派与流派配色；☰ 菜单 → 主题颜色也能快捷切。拖面板边缘可等比放大（以中心为准向四周放大、不出屏；竖版、横版各记一个比例，浮窗跟随当前布局），标题栏的最大化按钮或双击标题栏放到屏幕装得下的最大等比尺寸，拖边拉到最大也算最大化；还原回到 100%，最大化后拖标题栏也会还原；这里显示当前缩放、可一键复位（最大化时先取消最大化） | 无   |
| 5   | `settings-general-startup`  | 启动与权限：启动后自动开全局、开机自启、以管理员模式启动（新装默认开启，省掉网吧模式和游戏模式的提权重启）。自动开全局和管理员启动分别与开机自启互斥                                                                                                                                                                                                              | 无   |
| 6   | `settings-general-close`    | 关闭行为：关窗口时退出还是收进浮窗；最小化一律收浮窗；自动更新（关了只在标题栏提示，菜单里「检查更新」仍会下载）                                                                                                                                                                                                                                                   | 无   |
| 7   | 无                          | 完成。热键存在当前配置里，切配置会一起换                                                                                                                                                                                                                                                                                                                           | 无   |

## 常见坑

- ☰ → 关于可以查看管理员权限、当前输入通道、快速启动配置、WebView2，以及系统文字大小、显示器缩放、应用缩放和面板 / 浮窗尺寸。“刷新”重新采集；“复制环境信息”会重新采集后复制，附带实际页面视口、像素比、WebView 缩放和采集错误，反馈显示异常时可直接发送。
- ☰ → 前往官网在浏览器打开气质花产品页；☰ → 更多产品打开 `https://app.xwink.fun/`。☰ → 关于顶部「交流与联系」显示官网地址，可点击打开或点「复制链接」。这里也显示产品 QQ 群 `1127449168`，可点「复制群号」后在 QQ 中搜索加群，也可手动选中群号；邮箱仍可用于联系作者。官网「支持&帮助」提供同一群号和复制入口。
- 标题栏只显示面板显隐的快捷键，悬停查看用途，不额外显示「显隐」文字，为更新提示和窗口按钮留出空间。

- 应用界面不受 Windows“辅助功能 → 文字大小”影响，仍跟随显示器缩放。需要放大时拖动面板边缘；这里复位的是应用自己的缩放，不会修改 Windows 设置。

- 每步 `prepare` 打开设置并切到对应页签（hotkeys → hotkeys → sound → general → general → general），页签是受控的，弹窗已开时也能切。
- 互斥是真互斥：开「启动后自动开全局」或「以管理员模式启动」会把「开机自启」关掉并 toast 说明，反之亦然。开机自启拉起需要提权的程序会被系统静默拦下，同开等于开机不启动。
- 「启动后自动开全局」和手动点开一样会播报「全局启用」。它在面板加载完、输入模式恢复完之后才打开：启动时若弹出「以管理员模式恢复」确认框，要等点掉它才开；首次启动要先同意协议。
- 切换连发的开始／结束播报跟随实际启停事件，快速开关也会收到通知；同组换规则只播报新规则开始，长按插队的暂停与恢复不重复播报。声音总开关及对应时机的开关都需开启；新提示会替换正在播放的旧提示。
- 全局停止后会忽略迟到的规则播报，避免旧的「开始」通知盖掉停止提示；启动和切配置期间不播报规则启停。
- 教程不替用户绑热键、不改主题；用户在教程中真绑了也不影响流程。
- 设置弹窗在教程之下，气泡与高亮叠在弹窗之上。

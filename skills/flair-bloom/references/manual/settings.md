# 热键、声音与外观

对应应用内教程 `settings`。目标：设好全局热键（游戏里一键开关、收起 / 唤出面板）、按需开语音播报、换主题。

## 解决什么

游戏里不想切出来点面板：全局热键一键开关所有连发、显隐面板。看不到屏幕时靠声音知道连发开没开。主题颜色跟门派走。

## 步骤大纲

| #   | 目标锚点                 | 讲什么                                                                                                                                                                      | 实操 |
| --- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 1   | `settings-hotkeys`       | 三个热键：全局开关（可另设停止键）、面板显隐。只能是键盘键，Shift / Ctrl / Alt / Win 也行、左右分开识别；三者不能重复。点按键框开始捕获、按下要绑的键；已绑定的框上右键清除 | 无   |
| 2   | `settings-hotkeys`       | 绑了右 Alt 又绑左 Ctrl 会互相牵连（AltGr 键盘布局），界面会提示                                                                                                             | 无   |
| 3   | `settings-sound`         | 声音播报：全局启用 / 停用、切换连发开始 / 结束四个时机各自可开关；每个时机可选「朗读」文字或「音频」文件，能调音量、语速、音调                                              | 无   |
| 4   | `settings-general-theme` | 外观：明亮 / 黑暗 / 跟随系统，20 个门派配色；☰ 菜单 → 主题颜色也能快捷切                                                                                                   | 无   |
| 5   | `settings-general-startup` | 启动与权限：启动后自动开全局、开机自启、以管理员模式启动（省掉游戏模式的提权重启）。三者两两互斥，开一个自动关另一个                                                      | 无   |
| 6   | `settings-general-close` | 关闭行为：关窗口时退出还是收进浮窗；最小化一律收浮窗；自动更新（关了只在标题栏提示，菜单里「检查更新」仍会下载）                                                            | 无   |
| 7   | 无                       | 完成。热键存在当前配置里，切配置会一起换                                                                                                                                    | 无   |

## 常见坑

- 每步 `prepare` 打开设置并切到对应页签（hotkeys → hotkeys → sound → general → general → general），页签是受控的，弹窗已开时也能切。
- 互斥是真互斥：开「启动后自动开全局」或「以管理员模式启动」会把「开机自启」关掉并 toast 说明，反之亦然。开机自启拉起需要提权的程序会被系统静默拦下，同开等于开机不启动。
- 教程不替用户绑热键、不改主题；用户在教程中真绑了也不影响流程。
- 设置弹窗在教程之下，气泡与高亮叠在弹窗之上。

# 横版键鼠图与浮窗

对应应用内教程 `layouts`。目标：会用横版键鼠图直接点键设连发，知道怎么收进浮窗、浮窗上能做什么。

## 解决什么

竖版规则列表适合精细编辑；横版键鼠图一眼看清哪些键在用、点一下就设。玩游戏时主面板碍事，收成右下角一个常驻置顶小条。

面板和浮窗跟随显示器缩放，界面不受 Windows“辅助功能 → 文字大小”影响。需要更大的文字和按键时，拖动面板边缘等比放大，浮窗也会跟随。

## 步骤大纲

| #   | 目标锚点        | 讲什么                                                                                                                                            | 实操 |
| --- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 1   | `layout-toggle` | 标题栏这个按钮切换竖版 / 横版。网吧模式支持横版；外设模式下不能切横版（横版每个键都是「启动键 = 连发键」，外设模式仍限制这种切换连发）                                | 无   |
| 2   | `hkb-keyboard`  | 横版下直接点键：无 → 切换连发 → 长按连发 → 取消，三态轮换；右键有更多选项（启用、改模式、分组、删除）                                             | 无   |
| 3   | `hbar-legend`   | 图例：实心是长按连发、描边是切换连发、虚线是停用；数字角标是互斥组编号（实心 = 长按在组内，描边 = 切换在组内）；⚠ 表示这个键有横版表达不了的高级规则（启动键 ≠ 连发键、同键多规则），请回竖版编辑；悬停 ⚠ 键会画出走线，两种颜色分别是它触发的、触发它的 | 无   |
| 4   | `hbar-interval` | 横版所有单键规则共用一个间隔                                                                                                                      | 无   |
| 5   | `minimize`      | 点「—」收进浮窗：常驻置顶小条，位置可拖并记住，显示正在连发的键（呼吸高亮）、启动 / 暂停开关、展开主面板；可拖动                                  | 无   |
| 6   | 无              | 完成。关闭窗口时可选「切换到悬浮窗」还是退出，设置 → 通用里改                                                                                     | 无   |

## 常见坑

- 多步队列、独立停止键等复杂规则在触发键处显示高级标记；点击进入竖版编辑，不会快捷覆盖。横版统一间隔只修改可完整表达的一步规则，保留多步队列各自的间隔。浮窗在队列触发键旁显示当前步骤／总步数。

- 全局启用时，主面板与浮窗均有持续可见的描边和边缘呼吸。实际运行的键帽另有高对比描边、外圈脉冲与角落亮点；暂停键帽静止、变淡并显示 ⏸。实心／描边仍区分长按和切换模式。系统启用「减少动态效果」时不循环动画，保留描边和运行亮点。
- 整组在外设模式下不可用：`available` 返回「当前输入模式不支持横版键鼠图」，目录里禁用入口。网吧模式可用。
- 第 2 到 4 步 `prepare` 先切横版（窗口会变大并居中）；第 5 步 `prepare` 切回竖版，教程结束时布局停在竖版。
- 教程不真的最小化到浮窗：浮窗是另一个窗口，教程只在面板里讲。
- 浮窗上按 Alt+F4 是退出应用，不是把浮窗藏起来——浮窗藏了就只剩托盘图标，找不回来。

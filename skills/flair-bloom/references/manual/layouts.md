# 布局与浮窗

对应应用内教程 `layouts`。目标：会用横版键鼠图直接点键设连发，知道怎么收进浮窗、浮窗上能做什么。

## 解决什么

「竖版·规则卡片」适合精细编辑；「横版·键鼠按键」一眼看清哪些键在用、点一下就设。玩游戏时主面板碍事，收成右下角一个常驻置顶小条。

横版小键盘区与主键区底部对齐，顶部留出一行空位。

面板和浮窗跟随显示器缩放，界面不受 Windows“辅助功能 → 文字大小”影响。需要更大的文字和按键时，拖动面板边缘等比放大，浮窗也会跟随。

主面板的正文、按键键帽、菜单和表单控件统一使用系统 UI 字体，各组件保留自己的字号与字重。

主面板采用紧凑留白：顶栏、竖版规则区、横版键鼠区与底栏的四边内边距统一为 10px，并随面板等比缩放。

竖版底部「我要新建」按钮和窗口绑定控件与底栏按钮统一为 30px 高，窗口绑定的左右两部分等高。

常规按钮、输入框、规则卡、菜单、弹层与浮窗统一使用面板的 8px 圆角，规则卡和设置中的滑动开关保持胶囊轨道；快捷键提示键帽保留 5px 小圆角，与 Tab 筛选数量标记共用浅主色底和主色文字，在实色按钮内也保持浅底。分体控件只在外侧保留圆角，圆形图标与状态点使用圆形。

底栏的全局开关始终使用主色填充的胶囊按钮，开启与关闭时外观一致，文字显示「开始运行／结束运行」。布局切换使用弱化文字与无描边样式；模式下拉固定为中性描边。底栏的配置、模式下拉与窗口捕获共用表单输入组件的底色。按钮、窗口捕获的外框与分隔线、卡片和弹层的中性边框统一使用输入组件的边框色，随明暗主题切换；按钮悬停与按下时仍有底色和文字反馈。

## 常见坑

- Windows 的窗口绑定控件位于横版统一间隔右侧、竖版「我要新建」右侧。目标图标只随前台状态显示彩色或灰色；浮窗左侧显示应用 Logo、锁链及目标图标，整块仍能拖动。绑定跟随配置，切走暂停输出，切回继续队列，详见 [多套配置](profiles.md#窗口绑定)。

- 多步队列、独立停止键等复杂规则在触发键处显示高级标记；点击进入竖版编辑，不会快捷覆盖。横版统一间隔只修改可完整表达的一步规则，保留多步队列各自的间隔。浮窗在队列触发键旁显示当前步骤／总步数。

- 全局启用时，主面板与浮窗均有持续可见的描边和边缘呼吸。实际运行的键帽另有高对比描边、外圈脉冲与角落亮点；暂停键帽静止、变淡并显示 ⏸。实心／描边仍区分长按和切换模式。系统启用「减少动态效果」时不循环动画，保留描边和运行亮点。
- 视觉强化默认开启，开始运行后主面板和浮窗出现两道等距、每秒一圈的内边框梭形流光，横版、竖版和浮窗自动采用大、中、小三档尺寸；流光和边框适配主题色与明暗，切换布局重新计算完整轨迹。窗口尺寸、缩放与拖边范围保持原样。
- 主面板和浮窗 Logo 未运行时去色，运行时恢复彩色，每 0.4 秒脉冲并扩散虚影。「设置 → 通用 → 外观」关闭视觉强化会停止流光和 Logo 脉冲虚影，保留原有高亮；系统减少动态效果时保留静态状态。浮窗「未连发」保持小字号、单行显示。
- 流光头保持细小实心，直接使用所在面板的文字色，长尾跟随主题渐隐。
- 整组在外设模式下不可用：`available` 返回「此模式不支持横版」，目录里禁用入口。网吧模式可用。
- 第二步展示横版键鼠图，第三步切回竖版介绍浮窗入口；教程不实际最小化窗口。
- 教程不真的最小化到浮窗：浮窗是另一个窗口，教程只在面板里讲。
- 浮窗上按 Alt+F4 是退出应用，不是把浮窗藏起来——浮窗藏了就只剩托盘图标，找不回来。

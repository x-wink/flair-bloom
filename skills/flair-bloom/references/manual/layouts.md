# 横版键鼠图与浮窗

对应应用内教程 `layouts`。目标：会用横版键鼠图直接点键设连发，知道怎么收进浮窗、浮窗上能做什么。

## 解决什么

竖版规则列表适合精细编辑；横版键鼠图一眼看清哪些键在用、点一下就设。玩游戏时主面板碍事，收成右下角一个常驻置顶小条。

## 步骤大纲

| #   | 目标锚点        | 讲什么                                                                                                                                            | 实操 |
| --- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 1   | `layout-toggle` | 标题栏这个按钮切换竖版 / 横版。DD 驱动下不能切横版（横版每个键都是「启动键 = 连发键」，DD 驱动不支持这种切换连发）                                | 无   |
| 2   | `hkb-keyboard`  | 横版下直接点键：无 → 切换连发 → 长按连发 → 取消，三态轮换；右键有更多选项（启用、改模式、分组、删除）                                             | 无   |
| 3   | `hbar-legend`   | 图例：颜色分别是切换连发、长按连发、停用；数字角标是互斥组编号；⚠ 表示这个键有横版表达不了的高级规则（启动键 ≠ 连发键、同键多规则），请回竖版编辑 | 无   |
| 4   | `hbar-interval` | 横版所有单键规则共用一个间隔                                                                                                                      | 无   |
| 5   | `minimize`      | 点「—」收进浮窗：常驻置顶小条，位置可拖并记住，显示正在连发的键（呼吸高亮）、启动 / 暂停开关、展开主面板；可拖动                                  | 无   |
| 6   | 无              | 完成。关闭窗口时可选「切换到悬浮窗」还是退出，设置 → 通用里改                                                                                     | 无   |

## 常见坑

- 整组在 DD 驱动下不可用：`available` 返回「当前输入模式不支持横版键鼠图」，目录里禁用入口。
- 第 2 到 4 步 `prepare` 先切横版（窗口会变大并居中）；第 5 步 `prepare` 切回竖版，教程结束时布局停在竖版。
- 教程不真的最小化到浮窗：浮窗是另一个窗口，教程只在面板里讲。
- 浮窗上按 Alt+F4 是退出应用，不是把浮窗藏起来——浮窗藏了就只剩托盘图标，找不回来。

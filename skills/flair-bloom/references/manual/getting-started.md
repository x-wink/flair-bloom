# 上手三步

对应应用内教程 `getting-started`（`apps/main/src/windows/panel/tour/tours/getting-started.ts`）。目标：安装后五分钟内配好并跑起第一条规则。教程版本与上次自动展示过的对不上时（新装用户、或教程内容更新后）在启动时自动进入这一组，跑完或中途退出都记下版本，不会反复打扰。

## 解决什么

用户可以任选开关或长按规则，录键并启用，再开始运行。引导只讲这三步。

新装默认使用网吧模式并以管理员启动，按 Windows 提示授权即可，无需重启电脑；剑三推荐在模式菜单选择游戏模式。出厂配置默认按 **F1** 切换全局开关，也可直接点击按钮；已有配置以按钮上显示的快捷键为准。

首次安装同意协议后，会先询问是否扫描导入已有配置，由用户选「扫描配置」或「暂不导入」。支持 `.qzh` 与其他助手配置，扫描后仍需选择、预览并确认导入；关闭导入窗口后继续本教程。选择会记住，升级不会对老用户反复弹出；以后可从底栏「配置下拉 → 导入配置」直接打开。

Windows 安装器按用户选择创建桌面快捷方式，名称为「气质花 v版本号」。升级会迁移指向同一安装目录的旧快捷方式并更新版本号，不叠加旧版本；指向其他安装目录的同名链接会保留。未选择创建桌面快捷方式时不会强制新增。

## 步骤大纲

教程只保留基础流程，每步最多三句，每句不超过十字。完整功能说明保留在本篇参考段落。

| 步骤 | 目标锚点 | 气泡文案 | 实操判定 |
| --- | --- | --- | --- |
| 1 | add-toggle + add-hold | 选择开关或长按 | 新增一条规则 |
| 2 | rule-key + rule-enable | 点按键框录入；打开启用开关 | 录键并启用同一条规则 |
| 3 | global | 点击开始运行；按触发键连发；按所选类型停止 | 全局开始运行 |

## 引导规则

- 首步合并开关、长按两项的包围盒，规则组和分割线保持正常显示并留在遮罩外。两种规则都可完成首步，开关排在前面。
- 第二步合并同一张卡的按键与启用控件；必须成功录键并启用该规则，录入原按键也算完成。没有可见规则时跳过，不代建规则。
- 最后一步显示实际触发键，并按所选类型提示按一次或按住；已经开始运行时直接跳过。教程不改动录键、启停或菜单逻辑。

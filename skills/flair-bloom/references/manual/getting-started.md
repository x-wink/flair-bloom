# 上手三步

对应应用内教程 `getting-started`（`apps/main/src/windows/panel/tour/tours/getting-started.ts`）。目标：安装后五分钟内配好并跑起第一条规则。教程版本与上次自动展示过的对不上时（新装用户、或教程内容更新后）在启动时自动进入这一组，跑完或中途退出都记下版本，不会反复打扰。

## 解决什么

用户装好后面对空面板不知道从哪下手。这一组只教最短路径：加一条按压连发规则、录一个键、打开总开关。

## 步骤大纲

| #   | 目标锚点      | 讲什么                                                                                   | 实操                 |
| --- | ------------- | ---------------------------------------------------------------------------------------- | -------------------- |
| 1   | `tabs`        | 两种连发：按压连发按住就连、松手就停；切换连发按一下开始、再按一下停。先从按压连发开始   | 无                   |
| 2   | `add-hold`    | 点「+ 添加按压连发规则」，下面出现一张规则卡                                             | 规则数增加           |
| 3   | `rule-key`    | 点一下按键框，再按键盘或鼠标上要连的那个键（键盘、鼠标左右中侧键、滚轮都行）             | 新规则的连发按键改变 |
| 4   | `rule-enable` | 勾上右侧开关启用这条规则。间隔默认 10ms（也是最快值），多条一起连时软件会自动控速        | 规则已启用           |
| 5   | `global`      | 点右下角「全局已禁用」让它变「全局已启用」，背景变色就生效了。按住那个键自动连发，松手停 | 全局开关为开         |
| 6   | 无            | 完成。提示 ☰ 菜单里还有更多教程；玩游戏请看「游戏模式与驱动」                           | 无                   |

## 常见坑

- 用户在横版布局下进入教程：第 1 步的 `prepare` 先切回竖版，横版没有页签与规则卡。
- 第 2 步被「跳过这步」且列表仍为空：第 3、4 步 `prepare` 返回 `skip`，直接到第 5 步总开关，不会指着空处讲。
- 用户在「切换连发」页签下进入：第 2 步的 `prepare` 先切到「按压连发」。
- 第 3 步的判定以「连发按键与进入本步时不同」为准，用户录成鼠标键也算完成。
- 游戏里没反应不在这一组解释，交给「游戏模式与驱动」。

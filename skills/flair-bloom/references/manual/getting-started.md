# 上手三步

对应应用内教程 `getting-started`（`apps/main/src/windows/panel/tour/tours/getting-started.ts`）。目标：安装后五分钟内配好并跑起第一条规则。教程版本与上次自动展示过的对不上时（新装用户、或教程内容更新后）在启动时自动进入这一组，跑完或中途退出都记下版本，不会反复打扰。

## 解决什么

用户装好后面对空面板不知道从哪下手。这一组只教最短路径：加一条长按连发规则、录一个键、打开总开关。

新装默认使用网吧模式并以管理员启动，按 Windows 提示授权即可，无需重启电脑；剑三推荐在模式菜单选择游戏模式。出厂配置默认按 **F1** 切换全局开关，也可直接点击按钮；已有配置以按钮上显示的快捷键为准。

首次安装同意协议后，会先询问是否扫描导入已有配置，由用户选「扫描配置」或「暂不导入」。支持 `.qzh` 与其他助手配置，扫描后仍需选择、预览并确认导入；关闭导入窗口后继续本教程。选择会记住，升级不会对老用户反复弹出；以后可从「☰ → 导入配置」直接打开。

Windows 安装器按用户选择创建桌面快捷方式，名称为「气质花 v版本号」。升级会迁移指向同一安装目录的旧快捷方式并更新版本号，不叠加旧版本；指向其他安装目录的同名链接会保留。未选择创建桌面快捷方式时不会强制新增。

## 步骤大纲

| #   | 目标锚点      | 讲什么                                                                                   | 实操                 |
| --- | ------------- | ---------------------------------------------------------------------------------------- | -------------------- |
| 1   | `add-buttons` | 两种连发：长按连发按住就连、松手就停；切换连发按一下开始、再按一下停。先从长按连发开始   | 无                   |
| 2   | `add-hold`    | 点「+ 长按连发」，下面出现一张规则卡                                             | 规则数增加           |
| 3   | `rule-key`    | 点一下按键框，再按键盘或鼠标上要连的那个键（键盘、鼠标左右中侧键、滚轮都行）             | 新规则的连发按键改变 |
| 4   | `rule-enable` | 勾上右侧开关启用这条规则。间隔默认 10ms（也是最快值），多条一起连时软件会自动控速        | 规则已启用           |
| 5   | `global`      | 点右下角「全局已禁用」让它变「全局已启用」，面板出现明显描边和呼吸提示。按住设置的键自动连发，松手停；实际运行的规则另有脉冲高亮 | 全局开关为开         |
| 6   | 无            | 完成。提示 ☰ 菜单里还有六组教程；玩游戏请看「游戏模式与驱动」                           | 无                   |

## 常见坑

- 用户在横版布局下进入教程：第 1 步的 `prepare` 先切回竖版，横版没有筛选条与规则卡。
- 第 2 步被「跳过这步」且列表仍为空：第 3、4 步 `prepare` 返回 `skip`，直接到第 5 步总开关，不会指着空处讲。
- 用户停在某个筛选下进入：第 1、2 步的 `prepare` 先切回「全部」，新加的卡一定看得见。
- 第 3 步的判定以「连发按键与进入本步时不同」为准，用户录成鼠标键也算完成。
- 游戏里没反应不在这一组解释，交给「游戏模式与驱动」。

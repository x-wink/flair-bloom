# 多套配置

对应应用内教程 `profiles`。目标：不同角色 / 心法各存一套规则，随手切换；能导出分享、导入别人的。

底栏「配置下拉 → 导入配置」和设置 → 配置文件中的「导入配置」打开同一窗口，支持 `.qzh` 和其他助手配置。首次安装同意协议后会邀请扫描，扫描和导入都由用户选择。我们的 `.qzh` 欢迎自行尝试解析，也欢迎编写兼容的导入、导出和转换工具。

## 解决什么

一个角色一套连发键位，切角色要重设很烦。配置文件（`.qzh`）把规则、热键整套存起来，底部一键切换，托盘不开面板也能换。

新建配置时可勾选「复制当前规则」，每次默认不勾选：不勾选创建空规则配置，勾选则复制当前全部规则与规则组。热键、署名和高级设置沿用当前配置。创建前先保存当前编辑，再用统一配置激活入口切换，引擎与界面同步加载新配置。修改默认配置时的自动另存仍保留完整规则。

## 窗口绑定

Windows 下对所有用户开放，绑定跟随当前配置保存、复制和 `.qzh` 分享。竖版入口位于「我要新建」右侧，横版位于统一间隔右侧；设置 → 配置文件也提供当前配置的绑定控件。名称按钮打开独立浮层，列出已打开窗口的标题、程序名与图标；顶部输入框按标题和程序名过滤，可刷新列表，「清空」解除当前绑定。旁边的捕获图标进入系统窗口点选，同时用浮层盖住面板并提示操作；Esc、点击捕获浮层或 20 秒未选择时取消。捕获时会停止当前输出，目标点击不传给目标程序。更换绑定后需重新启动规则。

绑定按程序文件名及窗口类名识别，不记录 PID、句柄或安装路径，程序重启或换机器后可重新识别。默认同一程序的窗口共用范围。查询程序名失败时，已有绑定可用记录的类名匹配；初次选取无法识别程序时会提示尝试管理员身份。系统窗口和 UWP 宿主不保证能区分真实应用。

切到其他程序时释放按键、暂停切换规则，切回从原队列位置和剩余等待继续；长按规则必须重新按住。全局关闭、换规则、换配置、换输入模式及退出会清除恢复资格；停止热键与规则停止键在等待期间仍可用。助手自身窗口允许试运行，切窗不改变总开关、不重复播报启停。

控件左侧显示目标图标；目标处于前台时为彩色，否则灰色，不受总开关影响。悬停显示绑定名称、程序名和等待原因。浮窗显示应用 Logo、锁链和目标图标，整个 Logo 区域仍可拖动；应用 Logo 表达总开关，目标图标只表达目标是否在前台，锁链始终表示绑定关系。图标缓存于本机设置，目标关闭后仍保留；新机器未识别到目标时显示通用窗口图标。候选列表与点选都排除助手自身窗口，点击面板捕获浮层只会取消，不会绑定助手。

目标图标的脉冲同时要求目标处于前台、全局启用及视觉强化开启；仅颜色不受全局开关影响。

## 兑换码与水印署名

☰ 菜单 →「兑换码」：输入作者给的兑换码点「激活」。兑换码只在这一步联网——先读会员服务协议的现行版本（第一次要勾选同意，「《xwink 会员服务协议》」点开是系统浏览器里的正文；以后协议没更新就默认勾选），再提交兑换码换回许可证，存在本机，之后断网也有效。激活成功会列出这张码带来的权益，每项有说明和「前往」按钮（署名是「去填写」，直达设置 → 配置文件）。兑换码可以叠加：再打开同一项是全部权益（同一项权益取最晚到期）和已激活的各张码，点「再兑换一张」继续加。同一张码再兑换会先问是否覆盖——覆盖要占用这张码的一次重新激活次数；重装或换电脑时用原来的码再激活即可。输错、作废、过期、次数用完、尝试太频繁、网络不通都有对应提示。

激活过带「自定义署名」权益的兑换码后，设置 → 配置文件多出「水印署名」一栏：写一段不超过 16 字的署名，面板背景的默认署名就换成它。署名存在当前配置里，切配置跟着换；导出的 `.qzh` 带着署名，对方没有这项权益时显示默认署名，署名原样留在文件里。改「默认配置」的署名会像改规则一样先另存成新配置。没有权益的用户看不到这一栏，教程也不讲。

## 常见坑

- 队列版配置保存在独立目录，首次使用会复制旧配置，旧目录保留。旧版与队列版各自修改不会自动互相覆盖；跨版本交换应使用导入／导出，接收方须使用支持队列的版本。

- 第 3 步 `prepare` 打开设置并切到「配置文件」页签，教程结束不替用户关弹窗。
- 教程不真的导入导出（要文件对话框），只讲入口。
- 全局热键存在配置文件里，切配置会一起换。
- 切换、导入、新建和管理配置前会先保存当前编辑；保存失败时会提示并中止本次操作，当前配置仍可继续编辑。导出和点击面板关闭按钮前也会先保存。
- 扫描桌面、下载及衍天、大肥鱼默认数据目录及其一级子目录，还会只读解析已知助手的桌面快捷方式，从目标程序／工作目录找配置；不执行快捷方式或源程序。管理目录之外的有效 `.qzh` 与丐帮高手、衍天高手、极简按键、小叽按键、大肥鱼按键配置一起列出，管理目录内已有的配置不作为扫描结果。可点「选择文件」，或手动指定 `.qzh`、JSON、INI 文件及目录。多档配置分别列出，每次选一个导入成新配置；同一文件与档位不会重复列出。
- `.qzh` 保留规则、热键、规则组、署名与高级设置，空规则配置也能导入；仍会执行版本迁移、间隔适配与加载期按键检查。导入生成名称不冲突的新副本并立即切换，不改源文件。
- 衍天普通长按 / 切换规则、轮转组、启用状态、全局开关和独立停止键可转换。双宏、多目标轮流执行、修饰键组合和无法映射的键跳过并提示；外观、语音、驱动选择、方案切换热键和窗口绑定不导入。连发周期取原按压时长加抬起间隔（受气质花 10～10000 ms 范围约束），按压时长由气质花调度器决定，不能保证原游戏采样效果。
- 极简的 INI 按键列表迁移为默认停用的同键长按规则，迁移启动／停止键；顺序自动循环、暂停和声音不复现，确认触发方式后再启用。小叽按方案导入按压与独立切换，独立切换转规则组；随总开关自动启动的规则转为默认停用的同键切换规则，导入后需确认并启用。持续按住、顺序切换、固定位置点击、宏循环不等价，跳过并说明；周期计入原 5 ms 按压宽度。
- 仓库只保留独立编写的转换逻辑与脱敏测试，不收录第三方源码、程序、真实配置、协议或授权记录。千机魔盒没有可核验样例，暂不支持，不会按程序名称猜测解析。

## 大肥鱼配置迁移

大肥鱼按键 V5.2 的主配置是 `%APPDATA%\PenJiujiu\config.json`，压缩包或 EXE 本身不是配置。扫描默认位置或选择主配置，会同时尝试读取它当前关联的 `macros/<宏名>.json`；也可单独选择 `macros` 目录中的任意录制 JSON。关联宏缺失或损坏时，基础配置仍可导入，预览会说明缺少的文件。

| 使用场景 | 导入结果 |
| --- | --- |
| 基础连发 | 保留键盘、鼠标和滚轮键位及连发周期；持续按住退化为点按连发，定时辅助动作退化为手动启停 |
| 多段宏 | 保留规则组和段顺序，按各段启动键手动切换；自动轮换尽量按原驻留时间展开为循环输出序列 |
| 目标序列／录制宏 | 保留目标顺序、重复按键和相邻录制事件的间隔，转成规则内的输出序列 |

- 所有导入规则默认停用，确认目标和启动键后再启用；打开全局开关仍需按规则启动键开始，再按停止。独立录制宏没有启动键时暂用首个目标键，可在高级设置修改。
- 组合键忽略 Ctrl／Shift／Alt／Win 修饰，保留主键；因此出现同启动键时，相同目标合并，不同目标按顺序合并。全局开关键也会忽略修饰，鼠标／滚轮全局热键或与规则冲突的绑定需重新设置。
- 同步发送退化为顺序点按；录制宏单次回放退化为循环，需要手动停止。独立按住时长、录制开头等待、定时停止、窗口限制、声音、驱动和外观不保留。
- 基础连发周期按 20～2000 ms 保留，录制间隔适配到 10～10000 ms。单条序列最多 256 步；自动轮换过长时降低点按频率以保留各段目标和驻留时间，仍无法容纳时保留完整手动规则组。目标或录制事件超过容量会明确说明截断范围，不改源文件。

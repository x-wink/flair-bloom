# 多套配置

对应应用内教程 `profiles`。目标：不同角色 / 心法各存一套规则，随手切换；能导出分享、导入别人的。

## 解决什么

一个角色一套连发键位，切角色要重设很烦。配置文件（`.qzh`）把规则、热键整套存起来，底部一键切换，托盘不开面板也能换。

## 步骤大纲

| #   | 目标锚点        | 讲什么                                                                                           | 实操 |
| --- | --------------- | ------------------------------------------------------------------------------------------------ | ---- |
| 1   | `profile`       | 底部左下角是当前配置。「默认配置」改动后会自动另存成新配置，默认配置本身不会被改坏               | 无   |
| 2   | `profile`       | 点它：切换、新建、管理                                                                           | 无   |
| 3   | `settings-tabs` | 设置 → 配置文件：重命名、删除、导出 `.qzh`、导入 `.qzh`；还能从其它按键工具的 `config.json` 导入 | 无   |
| 4   | 无              | 托盘右键也有「切换配置」，游戏里不开面板就能换                                                   | 无   |
| 5   | 无              | 完成。分享给朋友：导出的 `.qzh` 对方点「导入配置」选中即用；文件是加密的，别的软件打不开         | 无   |

## 兑换码与水印署名

☰ 菜单 →「兑换码」：输入作者给的兑换码点「激活」。只有这一步联网——先读会员服务协议的现行版本（第一次要勾选同意，「《xwink 会员服务协议》」点开是系统浏览器里的正文；以后协议没更新就默认勾选），再提交兑换码换回许可证，存在本机，之后断网也有效。激活成功会列出这张码带来的权益，每项有说明和「前往」按钮（署名是「去填写」，直达设置 → 配置文件）。兑换码可以叠加：再打开同一项是全部权益（同一项权益取最晚到期）和已激活的各张码，点「再兑换一张」继续加。同一张码再兑换会先问是否覆盖——覆盖要占用这张码的一次重新激活次数；重装或换电脑时用原来的码再激活即可。输错、作废、过期、次数用完、尝试太频繁、网络不通都有对应提示。

激活过带「自定义署名」权益的兑换码后，设置 → 配置文件多出「水印署名」一栏：写一段不超过 16 字的署名，面板背景的默认署名就换成它。署名存在当前配置里，切配置跟着换；导出的 `.qzh` 带着署名，对方没有这项权益时显示默认署名，署名原样留在文件里。改「默认配置」的署名会像改规则一样先另存成新配置。没有权益的用户看不到这一栏，教程也不讲。

## 常见坑

- 第 3 步 `prepare` 打开设置并切到「配置文件」页签，教程结束不替用户关弹窗。
- 教程不真的导入导出（要文件对话框），只讲入口。
- 全局热键存在配置文件里，切配置会一起换。

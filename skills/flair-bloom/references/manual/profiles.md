# 多套配置

对应应用内教程 `profiles`。目标：不同角色 / 心法各存一套规则，随手切换；能导出分享、导入别人的。

「☰ → 导入配置」和设置 → 配置文件中的「导入配置」打开同一窗口，支持 `.qzh` 和其他助手配置。首次安装同意协议后会邀请扫描，扫描和导入都由用户选择。我们的 `.qzh` 欢迎自行尝试解析，也欢迎编写兼容的导入、导出和转换工具。

## 解决什么

一个角色一套连发键位，切角色要重设很烦。配置文件（`.qzh`）把规则、热键整套存起来，底部一键切换，托盘不开面板也能换。

## 步骤大纲

| #   | 目标锚点        | 讲什么                                                                                           | 实操 |
| --- | --------------- | ------------------------------------------------------------------------------------------------ | ---- |

| 2   | `profile`       | 点它：切换、新建、管理                                                                           | 无   |

| 4   | 无              | 托盘右键也有「切换配置」，游戏里不开面板就能换                                                   | 无   |

## 兑换码与水印署名

☰ 菜单 →「兑换码」：输入作者给的兑换码点「激活」。兑换码只在这一步联网——先读会员服务协议的现行版本（第一次要勾选同意，「《xwink 会员服务协议》」点开是系统浏览器里的正文；以后协议没更新就默认勾选），再提交兑换码换回许可证，存在本机，之后断网也有效。激活成功会列出这张码带来的权益，每项有说明和「前往」按钮（署名是「去填写」，直达设置 → 配置文件）。兑换码可以叠加：再打开同一项是全部权益（同一项权益取最晚到期）和已激活的各张码，点「再兑换一张」继续加。同一张码再兑换会先问是否覆盖——覆盖要占用这张码的一次重新激活次数；重装或换电脑时用原来的码再激活即可。输错、作废、过期、次数用完、尝试太频繁、网络不通都有对应提示。

激活过带「自定义署名」权益的兑换码后，设置 → 配置文件多出「水印署名」一栏：写一段不超过 16 字的署名，面板背景的默认署名就换成它。署名存在当前配置里，切配置跟着换；导出的 `.qzh` 带着署名，对方没有这项权益时显示默认署名，署名原样留在文件里。改「默认配置」的署名会像改规则一样先另存成新配置。没有权益的用户看不到这一栏，教程也不讲。

## 常见坑

- 队列版配置保存在独立目录，首次使用会复制旧配置，旧目录保留。旧版与队列版各自修改不会自动互相覆盖；跨版本交换应使用导入／导出，接收方须使用支持队列的版本。

- 第 3 步 `prepare` 打开设置并切到「配置文件」页签，教程结束不替用户关弹窗。
- 教程不真的导入导出（要文件对话框），只讲入口。
- 全局热键存在配置文件里，切配置会一起换。
- 切换、导入、新建和管理配置前会先保存当前编辑；保存失败时会提示并中止本次操作，当前配置仍可继续编辑。导出和点击面板关闭按钮前也会先保存。
- 扫描桌面、下载及衍天默认数据目录及其一级子目录，还会只读解析已知助手的桌面快捷方式，从目标程序／工作目录找配置；不执行快捷方式或源程序。管理目录之外的有效 `.qzh` 与丐帮高手、衍天高手、极简按键、小叽按键配置一起列出，管理目录内已有的配置不作为扫描结果。可点「选择文件」，或手动指定 `.qzh`、JSON、INI 文件及目录。多档配置分别列出，每次选一个导入成新配置；同一文件与档位不会重复列出。
- `.qzh` 保留规则、热键、规则组、署名与高级设置，空规则配置也能导入；仍会执行版本迁移、间隔适配与加载期按键检查。导入生成名称不冲突的新副本并立即切换，不改源文件。
- 衍天普通长按 / 切换规则、轮转组、启用状态、全局开关和独立停止键可转换。双宏、多目标轮流执行、修饰键组合和无法映射的键跳过并提示；外观、语音、驱动选择、方案切换热键和窗口绑定不导入。连发周期取原按压时长加抬起间隔（受气质花 10～10000 ms 范围约束），按压时长由气质花调度器决定，不能保证原游戏采样效果。
- 极简的 INI 按键列表迁移为默认停用的同键长按规则，迁移启动／停止键；顺序自动循环、暂停和声音不复现，确认触发方式后再启用。小叽按方案导入按压与独立切换，独立切换转规则组；随总开关自动启动的规则转为默认停用的同键切换规则，导入后需确认并启用。持续按住、顺序切换、固定位置点击、宏循环不等价，跳过并说明；周期计入原 5 ms 按压宽度。
- 仓库只保留独立编写的转换逻辑与脱敏测试，不收录第三方源码、程序、真实配置、协议或授权记录。千机魔盒没有可核验样例，暂不支持，不会按程序名称猜测解析。

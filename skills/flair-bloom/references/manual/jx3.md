# 剑网三专栏

对应应用内教程 `jx3`。目标：会打开专栏、按门派心法找到白皮书和宏，把宏复制进游戏。

## 解决什么

配连发之前通常要先查心法白皮书和宏。专栏按门派 → 心法列出白皮书与宏的标题、作者和原文链接，宏可以直接复制：云端宏复制 `作者#宏名`，在游戏插件里粘贴即可同步；作者授权收录了正文的宏，复制正文粘贴进游戏的宏编辑。人人可用，不需要兑换码。

## 步骤大纲

教程只保留基础流程，每步最多三句，每句不超过十字。完整功能说明保留在本篇参考段落。

| 步骤 | 目标锚点 | 气泡文案 | 实操判定 |
| --- | --- | --- | --- |
| 1 | jx3-pickers | 这里选择门派心法 | 无 |
| 2 | jx3-papers | 这里查看心法攻略 | 无 |
| 3 | jx3-macros | 这里复制游戏宏；复制后粘贴到游戏 | 无 |

## 界面细节

- 标题栏右侧「JX3Box ↗」打开 JX3Box 首页。
- 底部一行写列表更新日期，⟳ 重新从官网取；没取到时写「未连上官网」和用的是哪份，悬停看完整原因。官网的列表格式比应用新时提示更新应用。
- 只收重制版的心法与内容。

## 常见坑

- 三步都定位专栏中的基本入口，结束与退出会关闭教程打开的专栏。
- 专栏打开时列表还没取到，第一步的锚点会晚一点出现；启动时已经预取过，通常直接就有。
- 链接只能打开列表里出现过的 https 地址；复制失败（剪贴板被占用）会提示手动选中复制。

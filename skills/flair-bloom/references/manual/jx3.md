# 剑网三专栏

对应应用内教程 `jx3`。目标：会打开专栏、按门派心法找到白皮书和宏，把宏复制进游戏。

## 解决什么

配连发之前通常要先查心法白皮书和宏。专栏按门派 → 心法列出白皮书与宏的标题、作者和原文链接，宏可以直接复制：云端宏复制 `作者#宏名`，在游戏插件里粘贴即可同步；作者授权收录了正文的宏，复制正文粘贴进游戏的宏编辑。人人可用，不需要兑换码。

## 步骤大纲

| #   | 目标锚点      | 讲什么                                                                                                                         | 实操 |
| --- | ------------- | ------------------------------------------------------------------------------------------------------------------------------ | ---- |
| 1   | `menu`        | ☰ 菜单 → 剑网三专栏。列表启动时从官网取，取不到用上次的缓存或安装包内置的一份                                                    | 无   |
| 2   | `jx3-pickers` | 左边门派下拉（色块网格，门派与流派分组，无相楼在「流派」里），默认选中当前主题色对应的；右边心法分段器                           | 无   |
| 3   | `jx3-papers`  | 白皮书段：「✓ 作者授权」的常驻，点开在默认浏览器看原文；公开收录的热门帖子折叠在「公开收录的热门 · N 条」里，标来源站点，展开后写明作者不希望收录可联系下架 | 无   |
| 4   | `jx3-macros`  | 宏段：一篇帖子一行，宏名按钮复制 `作者#宏名`；带正文的宏显示正文，「复制」复制正文                                               | 无   |
| 5   | 无            | 完成。还没有授权内容的心法显示邀请，「联系我们」打开产品页的支持&帮助                                                           | 无   |

## 界面细节

- 标题栏右侧「JX3Box ↗」打开 JX3Box 首页。
- 底部一行写列表更新日期，⟳ 重新从官网取；没取到时写「未连上官网」和用的是哪份，悬停看完整原因。官网的列表格式比应用新时提示更新应用。
- 只收重制版的心法与内容。

## 常见坑

- 第 2 到 4 步 `prepare` 打开专栏，第 1 步和最后一步收掉，教程结束不把对话框留在屏幕上。
- 专栏打开时列表还没取到，第 2 步的锚点会晚一点出现；启动时已经预取过，通常直接就有。
- 链接只能打开列表里出现过的 https 地址；复制失败（剪贴板被占用）会提示手动选中复制。

# 新手输入模式与快捷键默认值

Status: completed

## 决策

- 网吧模式置顶，用途说明为「方便快捷·无需重启」；游戏模式为「安全稳定·剑三推荐」；轻量模式为「网页办公·游戏无效」。保留 DD 同键误判说明。
- Windows 启动时在加载配置前按 `inputModeOnboardingVersion = 1` 一次性迁移轻量模式，保留游戏、外设及已移除模式的处理路径；显式提权切换参数在迁移后应用。
- 新装和轻量模式迁移时，未开启开机自启、未设置启动偏好才默认开启管理员启动；首轮恢复使用现有提权命令，UAC 被取消则保留轻量通道。
- 出厂配置默认绑定 F1；下版本首轮升级给未绑定且 F1 未被其他热键或规则占用的已有配置补上 F1。目录与文件双重标记确保清空后不重复补回，保留自定义键；以后导入及复制保留原值，不递增 schema。

# 规则组命名与快速创建

Status: completed

## 决策

- 功能名统一为「规则组」，操作为「新建规则组」「移入组」「移出组」；组头与教程简介使用「常用于多段宏自动切换」。教程说明同组只运行一条、切换替换、长按插队。
- 所有前端规则创建复用现有 `newRule`，组创建批量加入按键为主键区 1、2 的两条停用切换规则，沿用默认 10ms 间隔；规则菜单新建时再移入当前规则。成员与规则组通过现有规则保存链一次写入，不增加后端创建入口。
- 新组自动展开并允许改名；保留已有组名、规则及教程示例的固定 ID，教程定位使用实际示例组名兼容已保存示例。
- 规则组只从实际成员派生。旧版待命空壳仅在窗口内存中，不存在可迁移的配置记录；升级不恢复空壳，最后一名成员离开后自动解散，全部停用的有成员组仍保留，不递增 schema。

## 验证与交接

- 5 项单元测试覆盖默认按键与停用状态、组名去重、已有数据不变、菜单移入、共用创建默认值以及空组自动消失；前端共 93 项测试通过。
- 隔离浏览器使用实际规则组和规则卡，验证 405px 页面下描述完整显示、新建两条规则、重复创建、折叠后描述保留、移除最后成员不留空壳、解散保留规则；不访问用户配置或驱动。
- 类型检查、lint、格式、文档校验与生产构建通过。说明书、教程、产品页及更新日志同步提交。

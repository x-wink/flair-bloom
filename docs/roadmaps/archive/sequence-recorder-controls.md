# 序列录制与规则卡入口

Status: completed

## 决策与验收

- 单键在规则卡主行编辑，添加第二步后显示步骤列表，删回一步隐藏列表。
- 录制与添加步骤同排；录制按钮切换为「结束录制 F12」，倒数期间可在面板提前结束。结束仅生成预览，不点「采用」就保留当前序列，不提供单独取消入口。
- 切换连发的启动键和停止键并排收入高级设置；收起时修改输出键不覆盖启动键。独立长按键保留在主行。
- 隔离浏览器验证列表显隐、按钮位置、F12 提前结束、录制未采用与采用、启动键位置及独立编辑；不操作真实用户配置，不重复提权或驱动真机验证。

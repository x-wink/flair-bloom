# 运行边框流光

Status: completed

「设置 → 通用 → 外观」提供默认开启的视觉强化开关，同时控制边框梭形流光和 Logo 脉冲虚影，关闭后保留原有描边、呼吸和键帽光晕。Logo 未运行时灰调，运行时彩色、按 0.4 秒周期脉冲。系统减少动态效果时保留静态状态。

偏好存入应用级 `visualEnhancement`，跨窗口广播同步，缺失时默认开启，显式关闭在重启后保留。单个 Canvas 按屏幕刷新回调绘制连续渐变，尾端贴内边框、向亮头倾斜，两道等距流光固定每秒一圈；横版／竖版／浮窗自动匹配三档尺寸，切布局与尺寸变化重建路径和时钟。主题色及明暗驱动边框与流光配色，不改变窗口尺寸、缩放与拖边区域，不增加引擎或键鼠事件工作。

流光头采用细小实心填充，直接跟随所在面板文字色，不叠加内芯；长尾保留主题色并渐隐，浮窗采用最细的一档。流光外缘全程压住高亮描边内缘半像素，消除细缝；Logo 虚影以 0.4 秒周期 ease-out 放大至 1.8 倍，透明度从 0.48 渐隐。

纯函数测试覆盖默认策略、三档尺寸、固定周期、等距流光、圆角轨迹连续闭合、贴边长尾整圈不越界，以及全部门派主题的明暗对比。浏览器夹具覆盖一秒回到原位、横版四边完整绕行、跨窗口同步、关闭后 Logo 和流光同时停止、重载保留关闭、迟到读取与保存不覆盖新选择、减少动态效果停止绘制，以及浮窗 11px 单行文字和覆盖层不拦截操作。前端类型、构建、提交检查及教程对应校验通过。

# 窗口绑定与规则操作区

Status: completed（代码与自动化验证完成，真实游戏送达另需对应环境验证）

Goal: 当前配置可限制到目标程序；切走暂停并释放按键，切回继续队列。绑定入口、图标状态与浮窗保持一致。

## 决策

- 窗口绑定对所有用户开放，不依赖许可证。
- 绑定跟随配置，放在 `meta.window_binding`，与署名共用元信息保存策略；不升 schema。程序文件名与窗口类名用于持久识别，不保存 PID、句柄或安装路径；同程序多个同类窗口共用范围。
- 竖版操作区左侧「我要新建」下拉包含长按、切换、规则组，右侧为窗口选择与桌面点选分体控件；横版放在统一间隔右侧。设置的配置文件页也可管理当前配置绑定。
- 分体控件采用一个完整外框与内部竖分隔线，按钮等高；窗口名称过长时省略。名称按钮打开独立浮层，顶部提供过滤输入框、刷新与清空绑定。候选与点选均排除本进程的主面板、浮窗及对话框。
- 目标图标仅表达目标是否在前台，与总开关和输出闸门独立。前台彩色、切走灰色；浮窗显示应用 Logo、锁链、目标图标，整块保持可拖动，应用 Logo 继续表达总开关。
- 图标优先从窗口读取，再尝试窗口类与程序文件；用黑白底绘制还原透明度，兼容旧式掩码。32px RGBA 通过同一 IPC 返回，本机缓存不进入 `.qzh`；未获取时使用通用窗口图标。
- 自家窗口前台允许试运行。切走不改总开关，不重复播报；暂停保留切换规则游标与剩余等待，长按及一次性点按释放。停止、改规则、换配置、换输入后端或退出取消恢复资格。
- 输入路由代际与调度代际分离，防止切走前在途触发在切回后启动，同时保留暂停队列；全局与规则停止键不受窗口闸门阻挡。
- 前台检测使用独立 WinEvent 消息线程；回调只发通知，工作线程重采当前前台，先计算输出闸门再读取候选与图标。捕获时以浮层遮住面板并提示操作，20 秒、Esc 或点击浮层取消；取消标志在启动原生任务前建立，避免快速取消丢失。目标点击不传给目标程序，自身点击交给遮罩取消处理。
- 顶栏增加「规则组」筛选，展示完整成员。拖入组任何区域均高亮组范围，底部文案变为「松手放置」；只有悬停底部区域本身时才额外高亮组尾位置。原卡保持 40% 不透明度，系统拖拽图像使用独立不透明快照。
- 主题标签统一为「颜色 · 门派」，应用与官网复用同一格式函数。

## 边界

- 默认按程序与类名匹配，不提供后台定向发送，也不自动切换配置。
- UWP 宿主、反作弊限制查询、管理员窗口的实际送达效果需对应环境验证；不能把已入队等同于游戏已接收。
- 多目标列表与标题条件编辑界面暂不提供；数据结构保留可选标题条件，但不扩展 schema。
- 图标读取失败不影响绑定判定；新机器先显示通用图标，目标出现后再缓存。

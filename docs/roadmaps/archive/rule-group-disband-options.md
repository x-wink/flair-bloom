# 解散规则组时可选删除成员

Status: completed

## 决策

- 解散确认框提供「同时删除组内规则」，每次按目标组规则的启用设置决定默认值：全部停用则勾选，有规则启用则不勾选，不记忆上次选择；其他组和未分组规则不参与判断。
- 未勾选时确认按钮为「解散」，勾选后为「清空并解散」，取消勾选恢复「解散」。
- 未勾选只清除目标组的成员关系，勾选后只删除目标组成员；取消确认不修改数据。
- 解散与删除复用现有规则更新、停止和自动保存链，不增加额外确认或后端入口。

## 验证与交接

规则组单元测试覆盖全部停用、有启用规则、目标组不存在、保留或删除成员、其他组与未分组规则隔离及源数据不变；TypeScript 和生产构建通过。说明书、教程与更新日志同步提交。

共用确认框的隔离浏览器验证覆盖按钮文案随勾选切换、取消后重开恢复默认、保留／删除选择正确传递，以及普通确认框正文与按钮行为兼容；未操作真实规则或用户配置。

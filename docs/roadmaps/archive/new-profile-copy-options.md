# 新建配置时选择复制规则

Status: completed

## 决策

- 新建配置确认框提供「复制当前规则」，每次默认不勾选；不勾选创建空规则副本，勾选复制当前全部规则和规则组，热键、署名及高级设置沿用当前配置。
- 复用 `fork_active_profile` 的可选 `copyRules` 参数；缺省保持完整复制，兼容默认配置的自动另存。新建前经过现有保存屏障，新建后通过 `load_profile` 激活，界面与引擎同步，源文件保持不变。
- 共用确认框允许复选项保持原确认按钮文字，新建配置始终显示「创建」；解散规则组的动态文案保留。

## 验证与交接

配置管理 26 项 Rust 测试、类型检查及生产构建通过，新增测试覆盖不复制、显式复制、缺省自动另存兼容、元信息与配置设置保留、落盘及源文件不变。隔离浏览器验证默认关闭、复制选择传递、切换勾选不清空名称、重开复位、取消不提交和解散按钮文案兼容；未操作真实用户配置。

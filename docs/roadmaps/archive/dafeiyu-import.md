# 大肥鱼按键 V5.2 配置迁移

Status: completed

## 格式依据

对用户提供的 V5.2 Windows x64 程序进行静态检查，核对 `config_path`、默认配置、配置读写、六槽位装载和主循环调度；没有执行源程序或驱动。程序 SHA-256：`a2c84389f0e817975b03154f52705e65d8dba18a40974e8d75a5ca3d4b29a0a6`。源程序、反汇编内容和安装工具均不入仓，仓内只保留独立转换代码与合成测试。

配置为 `%APPDATA%\PenJiujiu\config.json`，录制宏位于同级 `macros` 目录。`sets` 是两段槽位的镜像，支持 V5.2 六槽及历史两段各四槽，不丢弃已保存的旧段；顶层兼容键不再合并。无镜像时只转换明确存在的顶层键位。周期取源实际主循环的 20～2000 ms，不叠加独立按压宽度。

## 转换契约

- 按基础连发、多段宏、目标序列三种使用场景迁移，允许退化，不按来源功能是否等价执行过滤整条规则。差异由预览说明，导入规则全部停用供确认。
- `PARSERS` 共用扫描、预览、文件大小与 BOM 检查、`.qzh` 写入和统一激活流程；按格式扩展文件名匹配与关联文件准备，不增加导入入口。关联宏缺失或损坏不阻止基础配置导入，独立录制 JSON 也可单选。
- 基础槽位保留普通键盘、鼠标、源伪 VK 232／233 滚轮；忽略组合修饰保留主键，重合启动键的目标合并并说明。`key_seqs` 即使来源当前未执行也恢复其保存顺序，不按当前运行开关丢弃目标。
- 多段宏保留组和段顺序，自动轮换尽量展开驻留段；容量不够时降低频率，无法保留完整目标则回落手动组。独立录制按相邻时间戳生成目标步骤，单次回放退化手动停止的循环。
- 持续按住退化连发，同步发送退化顺序点按，辅助定时动作退化手动开关。驱动、窗口限制、外观、声音、独立按压宽度、开头等待、切键和复位快捷键不迁移。
- 默认扫描增加源数据目录，已知快捷方式名称增加大肥鱼；只读定位，不执行目标。

## 验证与边界

导入测试覆盖基础连发、六槽镜像、多段宏顺序、自动驻留展开与降频、目标序列与重复项、忽略修饰后的合并、录制事件时间、关联文件缺失／损坏／超限／目录越界、任意录制文件名、扫描去重、预览与实际转换一致、UTF-8 BOM、写入回读及源文件不变。未取得实际用户配置，当前验证依据为程序格式和合成样例；不涉及键鼠引擎与驱动行为变更。

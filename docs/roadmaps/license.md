# 许可证激活与亲友专属功能 — 设计稿

Status: draft
Goal: 亲友在应用内输入兑换码、联网一次，换回 billing 签发的离线许可证，激活亲友专属功能；之后离线校验，到期（如有）自动降级不锁死；将来接入 xwink 登录后可把许可证认领到账号名下。开工时转 active 并补任务卡与工期。

---

## 1. 背景

签发和登记都交给 xwink-console 的 billing 服务（[billing 路线图](https://cnb.cool/x-wink/playground/xwink-console) `docs/roadmaps/billing.md` 的 D47、L1 / L2 卡），flair 只负责激活请求、验签和功能开关。

| 能力           | 现状                                                                                                                                                |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 验签           | `packages/crypto/src/license.rs` 有 Ed25519 `verify_license` 与单测，但面向自签的 `QZHUA-…` 码，载荷是 `features` 位掩码，要改成验 billing 的许可证 |
| 签发           | `apps/keygen` 只有空壳；改由 billing 签发后不再需要                                                                                                 |
| 激活接口       | billing 的 `POST /licenses/activations`（L1 卡，依赖兑换码 B3 与部署单元 R1 上生产），未实现                                                        |
| 激活面板、开关 | 未实现                                                                                                                                              |
| 公钥           | 全零占位                                                                                                                                            |

## 2. 决策

- **D1：离线校验** — 理由：与「本地离线」的产品承诺一致；防时钟回拨靠载荷的 `iat` 下界校验。激活时联网见 D5。
- **D2：私钥只在 billing** — 不进主应用二进制，也不进本仓。
- **D3：有到期的许可证到期后自动降级，不崩溃、不锁死** — 亲友功能关闭，核心功能照常；`exp` 为空即永久。
- **D4：鼠标连发保持对所有用户开放** — 是否收敛为亲友专属在开工时决定。
- **D5：激活可以联网一次，不接受长期联网** — 作者定（2026-10-09）：像检查更新一样，由用户主动触发、明确提示要联网；激活之后离线校验；不用亲友功能的用户永远不联网。xwink 的权益凭证有效期只有分钟级，即使配成离线租约也要定期续期，不符合这一条，所以不用它。
- **D6：激活面板等 Vue 迁移 V1 之后再写** — 理由：[vue-migration](./vue-migration.md) 定了一步到位，不再新增 React 代码。
- **D7：匿名激活，以后可认领** — 作者定（2026-10-09，billing D47）：
  - 激活：亲友在应用内输入兑换码并勾选同意 xwink 会员服务协议，联网一次；billing 建一条未认领的许可证记录，返回签名的离线许可证，之后不再联网。
  - 重装或换机：同一个码在上限内可以重新下发同一许可证 id。
  - 认领：flair 接入 xwink 登录后，用户凭许可证把它认领到账号名下，转成单项权益，协议同意也转写进 uc。
  - 理由：要把 flair 并进 xwink 体系。只用自己的离线码、或匿名激活但不能认领，这批用户会永远游离在体系外；而让亲友先注册登录，成本又不划算。
- **D8：公钥构建时注入，按 kid 维护列表** — 作者定（2026-10-09）：
  - 注入方式：公钥放 GitHub Secrets，构建时注入。公钥不需要保密，放 Secrets 只是让公开仓里不出现它。
  - 密钥隔离：每个应用一把许可证密钥，和权益凭证的密钥分开，不进 JWKS（billing D21 的例外）。许可证头部带独立的类型标记与 `aud=flair`，flair 只认这两项都对的签名，所以这把私钥泄露不会外溢到其他服务。
  - 轮换与止血：新版本加新钥，旧钥只验不签。止血时新版本移除旧钥，代价是该钥签出的亲友许可证全部失效，要重新激活。
- **D9：内嵌公钥是顺手的门，不是防线** — 作者定（2026-10-09）：flair 开源免费，许可证只是亲友定制，被反编译或 fork 去掉校验影响不大；不做设备绑定，不上传硬件信息，许可证文件被拷走也接受。
- **D10：第一个亲友定制是自定义水印署名** — 作者定（2026-10-09）：
  - 内容：面板背景水印默认是作者署名「花间游悟 · 斗转星移」（`apps/main/src/windows/panel/PanelApp.css:75`，`.panel::after` 写死的 `content`）。持有权益键 `flair.signature` 时，水印显示配置文件里自定义的署名。
  - 字段：署名是一整段自由文本，存在每套配置里（`meta.signature`，`#[serde(default)]`，不升 schema 版本），切配置时水印跟着换。限长按字符数计（初值 16 字，实现时按竖版宽度调），去掉控制字符，由 `sanitize_profile` 统一净化。
  - 导出分享：导出的 `.qzh` 带上署名，导入方没有这项权益时显示默认署名，字段原样保留。
  - 入口：没有权益的用户界面上完全不露出署名入口。
  - 渲染：保留伪元素，面板根上有 `data-signature` 时用 `content: attr(data-signature)` 覆盖默认署名；没有权益或署名为空时不写这个属性，回落 CSS 里的默认值。`attr()` 取到的值按纯文本插入，不经 HTML 解析。只有配置里的编辑入口等 Vue 迁移 V1 之后再写。
  - 理由：署名是亲友最直观的「专属感」，改动面小，适合作为激活链路的第一个验收功能；flair 开源免费，亲友定制不对外宣传，所以不做锁定态。

## 3. 设计

### 许可证

- **激活请求**：`POST /licenses/activations`，请求体是兑换码、已同意的会员服务协议版本、可选的既有许可证 id（重下发时带上）。字段以 billing 的 owner 文档为准。
- **许可证载荷**：`license_id`、`aud`、权益键（`flair.<功能>`）、`iat`、可空的 `exp`；头部带 `kid` 与类型标记。
- **验签**：在 `packages/crypto` 里改写 `license.rs`：
  - 按 `kid` 从内嵌公钥列表选钥，校验类型标记与 `aud`，再按 `iat` / `exp` 判定。
  - 功能开关按权益键判断，替换 `feature_bits` 位掩码。
  - `apps/keygen` 删除。
- **存储**：许可证原文存在应用数据目录；每次启动离线验签，按权益键打开功能开关。
- **激活面板**：
  - 输入兑换码；勾选会员服务协议（正文在系统浏览器打开 uc 的协议页，界面显示协议版本）。
  - 明确提示「激活需要联网一次」；激活失败时区分码无效、已用完重下发次数、网络不通。
- **状态面板**：许可证 id、激活时间、到期时间（永久或剩余天数）、已授权功能。
- **到期提醒**：有到期的许可证，到期前 7 天在面板 banner 与桌宠状态气泡提醒。
- **产品承诺**：README 的「除检查更新外不联网」改为「除检查更新与激活兑换码外不联网」，与激活功能同一提交改。

## 4. 已知风险

- 系统时间回拨：`iat` 下界校验。
- billing 上生产的时间不在本仓控制内：L1 依赖兑换码 B3 与部署单元 R1。亲友专属功能本身可以先做，功能开关先用开发构建里的测试许可证验证。
- 公钥轮换止血会让旧许可证全部失效（D8），亲友要重新激活；同一个码在重下发上限内可以自助恢复。

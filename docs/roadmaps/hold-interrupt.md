# 长按插队互斥组 + 统一规则列表 — 改造路线图

Status: active
Goal: 长按连发规则能加入互斥组，按住时同组正在跑的规则让位、松手自动恢复；竖版取消页签改为统一列表以支持自由组合分组；横版高级规则用悬停走线可视化，两种布局行为与视觉语言一致。

---

## 0. 最终形态

### 0.1 用户看到的

**竖版**：顶部页签换成筛选标签，规则合并成一个列表，互斥组是列表里的容器，长按与切换规则可自由混排。

```
[全部 8]  [长按 3/4]  [切换 2/4]
─────────────────────────────────────────────
 ▮ 长按  Q → 左键         50ms   ☑    ⋯
 ▯ 切换  F1 → E           100ms  ☑    ⋯
▾ 采集宏 · 同一时间只跑一条，长按松手后恢复      ✎ 解散
 │ ▯ 切换  1 → 宏A  ⏸     80ms   ☑    ⋯
 │ ▯ 切换  2 → 宏B        80ms   ☑    ⋯
 │ ▮ 长按  侧键1 → F ●    30ms   ☑    ⋯
 └ 拖入规则
─────────────────────────────────────────────
 [＋ 长按连发]  [＋ 切换连发]
```

- ▮ 实心 = 长按，▯ 描边 = 切换；● 呼吸光晕 = 正在跑；⏸ + 降透明度 = 组内被暂停（仍算开启）。
- 点模式标签直接切换长按 / 切换；⋯ 菜单：移入分组 ▸ / 移出分组 / 改模式 / 删除。拖拽仍可用，是快捷方式。
- 筛选只影响显示：组容器照样显示，被过滤的成员折叠成一行「另有 N 条已隐藏」；筛选状态下禁止拖入分组。

**横版**：单键模型不变。长按规则可进组，组号角标按模式实心 / 描边；键帽 ⏸ 叠标表示被暂停；悬停任何参与高级规则的键，画电路排线风格的 SVG 走线，移开即退。

**浮窗**：激活规则样式与列表、键鼠图统一（实心 / 描边 + 半透明底），被暂停的加 ⏸。

### 0.2 行为规则（引擎）

一句话：**长按插队，切换让位；松手恢复。**

| 场景 | 行为 |
| --- | --- |
| 按切换规则的启动键 | 成为组内当前规则，其他切换规则停止（现状）。若此时有长按规则按着，它只成为「松手后恢复」的目标，不立刻跑 |
| 按下组内长按键 | 插队：当前跑的规则暂停（保留在 `active_rules`、标记 paused），长按规则开跑 |
| 松开长按键 | 还给上一个：栈里上一条仍按着的长按规则，或被暂停的切换规则 |
| 多条长按同时按住 | 后按的先跑，松手还给前一个；先松开栈中间的那条直接出栈，不影响栈顶 |
| 暂停期间按切换规则的停止键 | 该规则移出 `active_rules`，松手后不恢复 |
| 暂停期间按同组另一条切换规则的启动键 | 按现有互斥替换恢复目标，新规则保持暂停，松手后运行 |
| 组内没有别的规则在跑 | 长按规则就是普通按住连发 |
| 滚轮触发的长按规则 | 不插队，与同组切换同时跑 |
| 全局暂停、切换后端、退出 | 清空栈与暂停状态 |
| 声音播报 | 暂停 / 恢复不播报，只有切换规则真正开始 / 结束才播 |

## 1. 背景

- 需求来源：网站联系方式收到的第一封用户邮件，诉求是「切换连发跑着的时候，按住长按键临时接管，松手后继续」。
- 现状互斥只在切换规则之间（`handle_toggle_press` 过滤 `mode == Toggle`），长按规则 `start_rule` 不看组；前端切成长按时弹窗强制移出分组（`handleHSetMode`），横版却能把长按规则移入分组而引擎忽略——两种布局已经不一致。
- `BurstRule.group` 字段每条规则都有，本改动**不新增字段、不升 schema**。旧版本读到「长按带分组」直接忽略，行为等同现状，回退安全。
- 声音播报在前端靠 `activeRuleIds` 差分检测切换规则启停（`PanelApp.tsx:1079`），暂停的规则必须继续留在活跃集合里，否则一次插队会响两声。

## 2. 决策

- **D1：优先级固定「长按压过切换」，不做通用优先级字段。** 是否把长按规则放进组本身就是优先级开关；通用优先级唯一多表达的是「切换开着时长按没反应」，恰是最容易被当成故障的行为，且每张卡要多一个抽象数字与平局规则。
- **D2：组内不分区，自由混排。** 分区只是把模式重画一遍，且让人误以为是两种成员身份。组头一句话说明语义。
- **D3：正在按住的长按规则不会被切换规则挤掉。** 否则手指按着键却不连发，违背「按住就连」。
- **D4：竖版取消页签改统一列表 + 筛选标签**，而非第三个「互斥组」页签。互斥组本质是「几条规则放一起」，统一列表能在同一屏看到组成员并直接操作；引用式分组要在三个页签间来回跳。
- **D5：模式靠形状区分（实心 / 描边），不靠两种颜色。** 沿用 `HorizontalLayout.css` 的 `is-hold` / `is-toggle` 写法，色弱可辨、暗色主题只跟主色变量。「是什么模式」用色条与标签，「现在什么状态」用光晕 / ⏸，两件事不串味。
- **D6：口径统一为「长按连发 / 切换连发」**，标签写「长按 / 切换」。界面、说明书、教程同步。
- **D7：横版保持单键模型，高级规则继续只在竖版编辑。** 浮层编辑、双行键帽、规则条都否决：信息密度违背横版初衷，且同键多规则无论如何画不出来。「看」的问题用悬停走线解决（D8），不跳竖版（改动纠缠、影响面大）。
- **D8：横版悬停走线。** 悬停 / 聚焦任何参与高级规则的键（启动 ≠ 连发、同键多规则、或作为别人的连发 / 停止键）时画 SVG 走线，不悬停零密度。曼哈顿走线 + 45° 切角（PCB 排线风），多条并行错开 3～4px 扇出。**颜色表达输入输出**：从我出去 = 主色，指向我 = 成功色；启动 → 连发实线、启动 → 停止虚线；终点焊盘长按实心圆 / 切换空心圆 / 停止小方块。`stroke-dashoffset` 沿语义方向生长约 250ms，`prefers-reduced-motion` 直接显示。目标不在图上不画，现有 `title` 文字兜底。图例在有高级规则时显示两个色块。
- **D9：暂停状态由引擎推送。** 新命令 `get_rule_states` 返回 `{ running: string[], paused: string[] }`，面板与浮窗改用它；`get_active_rules` 保留语义（running ∪ paused）供播报差分。
- **D10：某组第一次同时含长按与切换时轻提示一次**（可勾选不再提示），存 `settings.json` 的 `holdInGroupHintDismissed`。双向触发：长按拖进切换组、切换拖进长按组、组内改模式，结果都是同一种混排，用户同样需要知道长按会插队。
- **D11：横版不动的限制**：DD 驱动下不能切横版（`key-policy` 里 DD 下重合态切换是空集）；左键三态轮换保留；单键统一间隔保留（只影响单键规则）。
- **D12：互斥组单独成一组教程 `groups`，从 `rules` 拆出。** `rules` 已有 7 步，再塞插队会超过「每组几分钟」；互斥组是「多段宏怎么不打架 + 长按怎么插队」两个概念，值得独立讲透。目录顺序放在「规则玩法」之后。
- **D13：互斥组教程用「示例组」实操，不只看不点。** 宿主提供 `createSampleGroup()`：建一个「示例·多段宏」组，含两条切换和一条长按，**全部停用**，三条固定 id 的规则都在才算已有（残留的部分示例规则当脏数据清掉重建）；「建示例组」按钮放在第 2 步气泡里，不在列表常驻（对老用户是噪音）。键位由宿主从候选里挑未被占用的（切换 1/2 → 3/4 → 5/6 → 7/8 → 9/0 → Z/X，长按 V/B/N/M/H/J，连发键从 Q/E/R/T/Y/U/I/O/P 依次挑三个；占用 = 全部规则的启动 / 连发 / 停止键 ∪ 三个全局热键），因为示例组按键撞上用户规则会同时触发并让冲突提醒变红；全被占用则不建并提示腾键位，可跳过。选键避开鼠标键（注入左键会点到面板自己）。用户在教程里亲手启用、按键、看组头状态，做完可一键删掉整组（`deleteSampleGroup`：固定 id ∪ 同名组的规则全删，删规则不是解散）。
- **D14：概念先用气泡内动画时间线讲，再实操验证。** 气泡 `body` 是 `ReactNode`，加一个 `tour/components/GroupTimeline.tsx`：四条泳道（按键 / 宏A / 宏B / 长按），按「按 1 → 按 2 → 按住 V → 松开 V」四拍播放，谁在跑谁暂停一目了然；`prefers-reduced-motion` 下静态展示最后一帧。用户先有画面，再去按真键对照。
- **D15：`TOUR_INTRO_VERSION` bump 到 `2`。** 「上手三步」第 1 步的锚点与文案随统一列表变了，老用户启动时再看一次。
- **D16：滚轮触发的长按不参与插队。** 滚轮每格是瞬发点按，没有「按住」；调度器 Stop → Tap → Start 与不停止在用户看来等价，却多一轮停启并打断切换规则的拍相位，不值得。
- **D17：分工。** 指挥 flair-bloom-2f，执行 flair-bloom-9e；执行方不 push、不推 tag。

## 3. 设计要点

### 引擎（`packages/burst-engine`）

- `ActiveRule` 存 `Arc<BurstRule>` + `paused: bool`；`RuntimeState` 加 `hold_stacks: HashMap<String, Vec<String>>`（按组分桶的按住中长按规则，按按下顺序，栈空即删键）。
- `start_rule`（Hold）：若 `rule.group` 存在，把同组 running 规则标 paused 并 `scheduler.stop_rule`；自身入栈。
- `stop_rule`（Hold release）：出栈；若自己是栈顶，恢复下一个候选：栈里上一条 → 否则同组 paused 的切换规则，调 `scheduler.start_rule`。
- `handle_toggle_press`：同组有长按在栈中时，新规则以 paused 插入而非启动；停止键命中 paused 规则直接移除。
- `tap_once_rule`（滚轮 Hold）：不插队（D16）。
- `stop_runtime_activity` / 后端切换：清栈与 paused。
- `get_active_ids` 不变；新增 `get_rule_states`。
- 单测覆盖 0.2 表每一行，重点：栈中间先松、暂停期间停止键、暂停期间切换替换、滚轮不插队。

### 竖版面板

- `PanelApp.tsx` 两段页签渲染合并；规则卡片抽成 `RuleCard` 组件（横版走线不复用它，但统一列表的两种模式共用）。
- 筛选状态 `filter: 'all' | 'hold' | 'toggle'`，仅影响渲染；`activeTab` 相关的教程锚点 `tabs` 改指筛选条。
- `handleHSetMode` 去掉移出分组弹窗，改为直接改模式（切换 → 长按清 `stop_key`）。
- 检查 `pushRules` 是否可撤销误拖；若不能，在本次不扩范围，记入风险。

### 横版

- 键帽按 `token(key)` 登记 `ref`；悬停时计算相对容器坐标，SVG 覆盖层 `pointer-events:none`，全在 `HorizontalLayout.tsx` + CSS，`PanelApp.tsx` 不动。
- 组号角标 `is-hold` 实心 / `is-toggle` 描边；`is-paused` 叠 ⏸。

### T8 冒烟记录（2026-09-25，dev 构建，通用模式，测试配置「测试-冒烟」）

环境：dev 从非管理员会话起，只能用通用模式（SendInput）。按键经 `relay_key_event` 注入引擎——面板聚焦时前端按键中继走的就是这个入口；冒烟规则的连发键用 F13～F20，避免打进别的窗口；做 groups 教程前先把面板切到前台（`document.hasFocus()` 为真）。证据是每步前后 `get_rule_states`。

| 切换启动互斥替换 | 通过：按 1 → R[t-a]；按 2 → R[t-b] |
